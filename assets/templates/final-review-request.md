# Final Review Request Template

## English

```text
Use the university final review skill. Read the uploaded course materials, identify the discipline category, and generate a complete final-exam review package.

Requirements:
- Course overview and discipline-specific review strategy
- Deep chapter-by-chapter notes
- Exam point prediction
- Question bank with answers and explanations
- Memorization outline
- Discipline-specific problem-solving / analysis templates
- Worked examples for calculations, proofs, experiments, cases, clinical reasoning, essays, business decisions, or design critique when applicable
- Final sprint checklist
- A polished DOCX / Word review handout using the style guide when requested
- A 100-point mock exam with answer key and scoring rubric
```

## 中文

要求：
- 课程总体框架和学科专属复习策略

- 考前冲刺清单
