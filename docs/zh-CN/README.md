# 大学期末复习 Skill 中文文档

这个目录包含 University Final Review Skill 的中文文档。

## 用途

这个 Skill 用来把大学课程资料转换成适合期末复习的资料。输入可以是 PPT、讲义、教材截图、作业、考纲、往年题或课堂笔记。

## 模块

1. [整体复习流程](overall-workflow.md)
2. [深度讲义生成](deep-lecture-notes.md)
3. [考点预测](exam-point-predictor.md)
4. [题库生成](question-bank-generator.md)
5. [背诵提纲](memorization-outline.md)
6. [计算题 / 算法题教练](calculation-algorithm-coach.md)
7. [输出格式](output-format.md)

## 推荐完整请求

```text
请使用大学期末复习 Skill，查看我上传的课程资料，生成完整期末复习资料，包括逐章深度讲义、考点预测、章节题库、背诵提纲、计算题/算法题解题模板，以及一套 100 分模拟卷。
```
