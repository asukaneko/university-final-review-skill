# 大学期末复习 Skill 中文文档

这个目录包含 University Final Review Skill 的中文文档。

## 用途

这个 Skill 用来把大学课程资料转换成适合期末复习的资料。它不只适用于计算机课程，也支持理学、医学、法学、文史哲、社会科学、经管、教育、艺术设计和通识课程。输入可以是 PPT、讲义、教材截图、作业、考纲、往年题、实验资料、案例材料或课堂笔记。

## 推荐完整请求

```text
请使用大学期末复习 Skill，先根据我上传的课程资料判断学科大类，然后生成完整期末复习资料，包括逐章深度讲义、考点预测、章节题库、背诵提纲、学科专属解题/分析模板、一份排版美观的 DOCX 文档，以及一套 100 分模拟卷。
```
