# 考点预测

这个模块用于根据课程资料分析期末考试可能出现的重点内容和题型。

## 每章输出内容

每一章建议输出：

1. 必考点
2. 高频考点
3. 低频但容易拿分的点
4. 可能的选择题考法
5. 可能的填空题考法
6. 可能的简答题考法
7. 可能的大题、计算题或分析题考法
8. 容易混淆的概念对比
9. 只剩 1 天时的复习优先级
10. 只剩 3 小时时的复习优先级

## 判断依据

优先关注以下内容：

- PPT 中反复出现的概念
- 标题、图示、公式、例题中强调的内容
- 作业或实验中出现的知识点
- 本章核心机制相关内容
- 容易改造成标准考试题的内容

## 优先级分级

| 优先级 | 描述 | 复习方法 |
| --- | --- | --- |
| 必考点 | 必定出现，是其他内容的基础 | 完全掌握，能从记忆中解题 |
| 高频考点 | 在往年题中多次出现或老师强调 | 扎实理解，能解释和应用 |
| 低频易拿分 | 考得少但准备了就能拿分 | 快速复习，确保基本熟悉 |
| 可能考点 | 取决于老师的出题选择 | 浏览并记要点 |

## 按题型分类的考点

### 选择题可能考点

- 定义及其区分特征
- 以下哪项正确/错误
- 规则的例外情况
- 具体数值或阈值

### 填空题可能考点

- 关键术语及其定义
- 公式中的变量及其含义
- 流程或算法的步骤
- 重要日期、人物或数字

### 简答题可能考点

- 比较两个概念的异同
- 解释一个机制或过程
- 列举要素或条件
- 描述一个实验或研究

### 大题/计算题/分析题可能考点

- 多步解题过程
- 需要判断的案例分析
- 设计或评价任务
- 多个概念的综合运用

## 时间维度的优先级

### 考前 1 天

重点复习：

1. 每章的必考点
2. 公式/规则表
3. 速记版和关键词
4. 易错点清单
5. 高频往年题模式

### 考前 3 小时

重点复习：

1. 速记版关键词
2. 公式速查
3. 易错点模式
4. 信心建立（复习已经掌握的内容）

## 注意事项

考点预测不是绝对押题，应明确说明这是"基于资料的考试倾向分析"。
