# 考点预测

这个模块用于根据课程资料分析期末考试可能出现的重点内容和题型。

## 每章输出内容

每一章建议输出：

1. 必考点
2. 高频考点
3. 低频但容易拿分的点
4. 可能的选择题考法
5. 可能的填空题考法
6. 可能的简答题考法
7. 可能的大题、计算题或分析题考法
8. 容易混淆的概念对比
9. 只剩 1 天时的复习优先级
10. 只剩 3 小时时的复习优先级

## 判断依据

优先关注以下内容：

- PPT 中反复出现的概念
- 标题、图示、公式、例题中强调的内容
- 作业或实验中出现的知识点
- 本章核心机制相关内容
- 容易改造成标准考试题的内容

## 注意事项

考点预测不是绝对押题，应明确说明这是“基于资料的考试倾向分析”。
