# 输出格式

输出应使用清晰、适合复习的 Markdown 结构。如果用户要求生成 DOCX / Word 文档，还应参考 [`docx-style-guide.md`](docx-style-guide.md) 中的排版规范。

## 推荐章节格式

```markdown
## 第 N 章：标题

### 1. 本章概述

### 2. 核心概念

### 3. 关键机制 / 公式 / 算法

### 4. 考点分析

### 5. 常见题型

### 6. 易错点

### 7. 一页速记版

### 8. 练习题
```

## 表格使用场景

以下内容建议使用表格：

- 概念对比
- 考点优先级
- 题型映射
- 公式总结
- 易错细节
- 案例分析结构
- 临床推理链条
- 法学构成要件

## 模拟卷格式

完整模拟卷应包含：

- 总分：100 分
- 建议答题时间
- 题型分布
- 每题分值
- 标准答案
- 评分要点

## DOCX 输出格式

当生成 DOCX 时，优先使用以下排版元素：

- 居中的课程标题和章节标题
- 页眉：课程名、章节名或主题
- 页脚：资料类型、页码或“学习笔记与考试重点整理”
- 浅蓝色“本章主线”框
- 学习目标列表
- 目录
- 深蓝表头的概念表和考点表
- 浅黄色“注意”框
- 浅红色“易错点”框
- 浅灰色公式、代码或示例块
- 章节之间适当分页

详细视觉规范见 [`docx-style-guide.md`](docx-style-guide.md)。

## 内容标注

必要时标注内容来源：

- `来自上传资料`
- `基于资料推测的考点`
- `补充背景知识`
