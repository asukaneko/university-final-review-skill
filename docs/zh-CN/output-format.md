# 输出格式

输出应使用清晰、适合复习的 Markdown 结构。

## 推荐章节格式

```markdown
## 第 N 章：标题

### 1. 本章概述

### 2. 核心概念

### 3. 关键机制 / 公式 / 算法

### 4. 考点分析

### 5. 常见题型

### 6. 易错点

### 7. 一页速记版

### 8. 练习题
```

## 表格使用场景

以下内容建议使用表格：

- 概念对比
- 考点优先级
- 题型映射
- 公式总结
- 易错细节

## 模拟卷格式

完整模拟卷应包含：

- 总分：100 分
- 建议答题时间
- 题型分布
- 每题分值
- 标准答案
- 评分要点

## 内容标注

必要时标注内容来源：

- `来自上传资料`
- `基于资料推测的考点`
- `补充背景知识`
