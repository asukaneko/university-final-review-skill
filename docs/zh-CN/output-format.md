# 输出格式

输出应使用清晰、适合复习的 Markdown 结构。如果用户要求生成 DOCX / Word 文档，还应参考 [`docx-style-guide.md`](docx-style-guide.md) 中的排版规范。

## 推荐章节格式

```markdown
## 第 N 章：标题

### 1. 本章概述

### 2. 核心概念

### 3. 关键机制 / 公式 / 算法

### 4. 考点分析

### 5. 常见题型

### 6. 易错点

### 7. 一页速记版

### 8. 练习题
```

## 表格使用场景

以下内容建议使用表格：

- 概念对比
- 考点优先级
- 题型映射
- 公式总结
- 易错细节
- 案例分析结构
- 临床推理链条
- 法学构成要件

## 模拟卷格式

完整模拟卷应包含：

- 总分：100 分
- 建议答题时间
- 题型分布
- 每题分值
- 标准答案
- 评分要点

## DOCX 输出格式

当生成 DOCX 时，优先使用以下排版元素：

- 居中的课程标题和章节标题
- 页眉：课程名、章节名或主题
- 页脚：资料类型、页码或“学习笔记与考试重点整理”
- 浅蓝色“本章主线”框
- 学习目标列表
- 目录
- 深蓝表头的概念表和考点表
- 浅黄色“注意”框
- 浅红色“易错点”框
- 浅灰色公式、代码或示例块
- 章节之间适当分页

详细视觉规范见 [`docx-style-guide.md`](docx-style-guide.md)。

## 内容标注

必要时标注内容来源：

- `来自上传资料`
- `基于资料推测的考点`
- `补充背景知识`

## 完整复习包

当用户要求“丰富”或“完整”输出时，应包含：

1. 课程和考试范围总览。
2. 学科大类和复习策略。
3. 基于学习科学的复习计划。
4. 逐章深度讲义。
5. 高频考点地图。
6. 概念对比表、公式/规则表。
7. 带答案和解析的章节题库。
8. 用于主动回忆的测试卡片，见 [`test-cards.md`](test-cards.md)。
9. 例题或范答。
10. 错题日志和薄弱点修复计划。
11. 精准 100 分模拟卷，见 [`precision-mock-exam.md`](precision-mock-exam.md)。
12. 最后冲刺清单。

## 精准模拟卷输出

模拟卷应包含：

- 试卷蓝图表；
- 总分和时长；
- 各部分作答说明；
- 带分值和预计用时的题目；
- 标准答案；
- 详细 Rubric；
- 部分给分说明；
- 常见陷阱；
- 按章节和能力维度给出的考后诊断。

## 测试卡片输出

测试卡片应按章节和卡片类型分组。包含 ID、正面、背面、章节、主题、难度、卡片类型和标签。
