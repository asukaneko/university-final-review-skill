# DOCX 文档排版指南

当用户要求导出 Word / DOCX，或者希望复习资料“好看、正式、适合打印、像学习讲义”时，使用本指南。

## 视觉目标

文档整体应像一份干净的大学课程复习讲义：

- 白色页面背景，留白充足。
- 深蓝色作为主要学术风格强调色。
- 浅蓝色提示框用于“本章主线 / 核心思路”。
- 浅黄色提示框用于“注意 / 考试提醒 / 条件限制”。
- 浅红色提示框用于“易错点 / 常见误区”。
- 深蓝色表头，白色文字。
- 浅灰色代码块、公式块、示例块。
- 页眉页脚清晰，适合手机阅读和打印阅读。

## 推荐颜色

| 颜色角色 | 用途 | 建议色值 |
| --- | --- | --- |
| 主蓝色 | 主标题、一级标题、表格表头 | `#1F5D8C` |
| 深蓝灰 | 正文标题 | `#1E3A56` |
| 浅蓝底 | 本章主线 / 核心提示框 | `#EAF3FB` |
| 浅黄底 | 注意 / 提醒框 | `#FFF6D9` |
| 浅红底 | 易错点 / 误区框 | `#FDEBEC` |
| 浅灰底 | 公式 / 代码 / 示例块 | `#F4F6F8` |
| 边框灰 | 表格边框和分隔线 | `#D8DEE6` |

## 页面布局

推荐页面设置：

- 纸张：A4。
- 页边距：左右 2.0 cm，上下 1.8-2.2 cm。
- 中文正文：使用清晰的无衬线中文字体。
- 英文正文：Calibri / Aptos 等无衬线字体。
- 正文字号：10.5-11 pt。
- 行距：1.15-1.25。
- 普通段落段后距：4-6 pt。

## 首页 / 章节首页结构

建议首页包含：

1. 顶部小字路径，例如：`课程名 | 第 N 章 | 主题`。
2. 课程主标题。
3. 章节标题。
4. 副标题，例如：`详细讲解与考试重点整理`。
5. 浅蓝色“本章主线”提示框。
6. 学习目标。
7. 目录。

## 标题层级

推荐标题样式：

- 文档标题：居中、大字号、主蓝色。
- 章节标题：居中、加粗、深蓝灰。
- 一级标题：主蓝色、加粗、带编号。
- 二级标题：深蓝灰、加粗、带编号。
- 重点术语：加粗。
- 必要时保留英文关键词，例如：`状态 state`、`动作 action`。

## 提示框样式

### 本章主线框

用于概括一章的核心逻辑。

- 底色：浅蓝。
- 标签：`本章主线`。
- 内容：用 1-3 句话说明本章如何从概念到题型。

### 注意框

用于考试提醒、前提条件、特殊规则。

- 底色：浅黄。
- 标签：`注意`。

### 易错点框

用于常见误区、容易混淆的结论。

- 底色：浅红。
- 标签：`易错点`。

### 公式 / 代码 / 示例块

用于公式、伪代码、代码片段、路径例子、推导片段。

- 底色：浅灰。
- 适合时使用等宽字体。
- 不要和正文混在一起。

## 表格样式

表格应便于扫读：

- 表头：深蓝底，白色加粗文字。
- 表体：白色或浅灰交替行。
- 边框：浅灰。
- 单元格留白紧凑。
- 概念表建议三列：`概念`、`含义`、`例子`。
- 考点表建议三列：`项目`、`重点`、`考试理解`。

## 每章推荐固定模块

每章可以按以下顺序排版：

1. 本章主线
2. 学习目标
3. 目录
4. 概念表
5. 原理 / 流程讲解
6. 公式 / 规则块
7. 例题或案例
8. 注意框
9. 易错点框
10. 考点表
11. 一页速记
12. 练习题

## 生成 DOCX 时的要求

生成 Word 文档时，应尽量使用真实 Word 样式，而不是只输出普通文本。需要包含标题样式、表格、底纹段落、分页、页眉页脚和一致的颜色系统。避免生成一整篇没有排版的纯文本。
