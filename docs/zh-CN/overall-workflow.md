# 整体复习流程

当用户要求生成完整大学期末复习资料时，使用这个流程。

## 输入资料

用户可能提供：

- PPT 课件
- 课堂讲义
- 教材片段
- 作业题
- 往年题
- 考纲或考试范围
- 课堂截图
- 实验报告
- 课程视频截图
- 笔记照片

## 工作流程

### 第一步：确认和规划

1. 确认课程名称、章节范围和考试范围。
2. 判断学科大类，选择对应的 [`categories/`](categories/README.md) 指南。
3. 评估可用资料的完整度，标注缺失部分。
4. 制定复习包生成计划。

### 第二步：结构提取

1. 根据资料建立章节结构。
2. 提取核心概念、定义、公式、流程、算法和图示。
3. 标注高频出现的内容和老师强调的重点。
4. 建立章节之间的逻辑关系图。

### 第三步：逐章深度生成

对每一章，按以下顺序生成：

1. 章节概述和在整门课中的地位。
2. 核心概念和定义。
3. 关键机制、公式、算法或结构图。
4. 面向考试的讲解。
5. 常见题型和解题思路。
6. 易错点和注意事项。
7. 概念对比表。
8. 一页速记版。
9. 练习题和答案。

### 第四步：考点分析

1. 分析高频考点和可能题型。
2. 预测各章节的考试权重。
3. 标注必考点、高频考点和低频但易拿分的点。
4. 提供只剩 1 天和只剩 3 小时的复习优先级。

### 第五步：题库生成

1. 生成章节练习题和答案解析。
2. 按难度分层（基础、常考、综合、迁移）。
3. 包含多种题型（选择、填空、简答、计算、案例等）。
4. 每道题附详细解析和常见错误。

### 第六步：主动回忆材料

1. 生成测试卡片（定义卡、对比卡、流程卡、应用卡等）。
2. 整理背诵提纲和考前速记清单。
3. 提供关键词串联记忆法和口诀。

### 第七步：解题教练

1. 对计算题、算法题、病例题、案例题等补充分步解题过程。
2. 提供学科专属的分析模板。
3. 包含示例题和常见变形。

### 第八步：模拟卷

1. 根据蓝图生成精准 100 分模拟卷。
2. 包含标准答案、评分 Rubric 和部分给分说明。
3. 提供考后诊断分析。

### 第九步：输出整理

1. 按统一格式整理所有内容。
2. 如需要，生成 DOCX 版本。
3. 如需要，生成交互式测试卡片 HTML。

## 默认完整输出

完整期末复习资料应包含：

1. 课程总体框架
2. 学科大类和复习策略
3. 章节结构
4. 逐章复习讲义
5. 考点优先级排序
6. 关键定义和核心概念
7. 概念对比表、公式/规则表
8. 常见题型
9. 易错点
10. 章节题库
11. 测试卡片（可导出 CSV 和交互式 HTML）
12. 背诵提纲
13. 错题日志和薄弱点修复计划
14. 考前冲刺清单
15. 精准模拟卷（含评分 Rubric）

## 资料依据规则

优先依据用户上传的资料。如果某个内容不是资料中直接出现的，但属于必要背景知识，需要标注为"补充背景"。

标注规则：

- `来自上传资料`：直接从用户提供的材料中提取。
- `基于资料推测的考点`：根据资料内容推断的考试重点。
- `补充背景知识`：资料中没有但必要的背景信息。

## 输出格式

根据用户需求选择输出格式：

- **Markdown**：默认格式，适合在线查看和编辑。
- **DOCX/Word**：适合打印和分享，参考 [`docx-style-guide.md`](docx-style-guide.md)。
- **交互式 HTML**：测试卡片专用，参考 [`test-cards.md`](test-cards.md)。

## 多学科组合

当课程涉及多个学科领域时：

1. 确定主要学科和次要学科。
2. 用主要学科的模板为主。
3. 补充次要学科的专属内容。
4. 在交叉部分用组合模板。

例如：

- 医学伦理：医学/健康 + 法学/人文。
- 教育心理学：教育 + 社会科学。
- 商法：商科/经济 + 法学。
- 技术写作：计算机/工程 + 人文学科。
- 健康经济学：医学/健康 + 经管/经济。

## 质量检查清单

完成复习包后检查：

- [ ] 章节结构是否完整覆盖考试范围。
- [ ] 概念定义是否准确、清晰。
- [ ] 公式和定理是否包含适用条件。
- [ ] 题库是否覆盖多种难度和题型。
- [ ] 答案解析是否足够详细。
- [ ] 易错点是否明确标注。
- [ ] 背诵提纲是否可直接使用。
- [ ] 模拟卷是否符合考试格式。
- [ ] 所有内容是否基于上传资料。
- [ ] 补充内容是否标注为"补充背景"。
