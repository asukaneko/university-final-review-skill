# 整体复习流程

当用户要求生成完整大学期末复习资料时，使用这个流程。

## 输入资料

用户可能提供：

- PPT 课件
- 课堂讲义
- 教材片段
- 作业题
- 往年题
- 考纲或考试范围
- 课堂截图
- 实验报告
- 课程视频截图
- 笔记照片

## 工作流程

### 第一步：确认和规划

1. 确认课程名称、章节范围和考试范围。
2. 判断学科大类，选择对应的 [`categories/`](categories/README.md) 指南。
3. 评估可用资料的完整度，标注缺失、看不清、重复或与考试范围不一致的部分。
4. 制定复习包生成计划。

### 第二步：资料盘点与结构提取

在正式写讲义前，先建立“资料覆盖清单”，避免遗漏资料信息，并为思维导图提供结构依据。

1. 按文件、章节、页码/幻灯片范围、标题层级建立资料目录。
2. 提取核心概念、定义、公式、流程、算法、图示、表格、例题、实验步骤、案例、作业题和往年题线索。
3. 标注高频出现的内容、标题加粗/层级较高内容、老师强调的重点、反复出现的关键词和题型线索。
4. 建立章节之间的逻辑关系图。
5. 为课程总览和每章总览提取思维导图节点：章节主题、一级模块、二级知识点、关键公式/流程/算法/图表、典型例题和高频考点。
6. 对资料中信息量大的单元标记为“必须展开”，不能只写摘要。

### 第三步：逐章深度生成

对每一章，按以下顺序生成：

1. 章节概述和在整门课中的地位。
2. 资料覆盖清单：本章使用了哪些上传文件、资料片段、图表、公式、例题、作业题或用户提到的内容。
3. 章节总览思维导图：用 Mermaid `mindmap`、缩进树或 DOCX 层级框展示本章知识结构。
4. 思维导图读图说明：指出先看哪些主干、哪些分支对应考试题型、哪些节点要背诵或会计算。
5. 核心概念和定义。
6. 关键机制、公式、算法、结构图、实验步骤或案例框架。
7. 面向考试的讲解。
8. 常见题型和解题思路。
9. 易错点和注意事项。
10. 概念对比表。
11. 一页速记版。
12. 练习题和答案。

逐章生成时必须遵守：

- 讲义内容必须能对应到实际上传资料或用户提到的资料范围，不能只写通用学科常识。
- 章节总览必须包含思维导图，且思维导图节点必须来自资料中的标题、图表、公式、流程、算法、例题、作业题或考点线索。
- 单元内容不能过少。资料中有实质内容的小节，应展开为“定义/结论 + 原理/流程 + 资料细节 + 例子/题型 + 易错点”。
- 不要损失资料信息。定义、公式、步骤、图表、例题、分类、条件、优缺点、案例要素和题型线索应保留或转写为复习表。
- 只能压缩重复表达，不能删除不同概念、不同条件、不同变形或不同例子。

### 第四步：考点分析

1. 分析高频考点和可能题型。
2. 预测各章节的考试权重。
3. 标注必考点、高频考点和低频但易拿分的点。
4. 提供只剩 1 天和只剩 3 小时的复习优先级。
5. 对每个重要考点说明依据：来自标题层级、反复出现、图表/公式、作业题、往年题、例题或老师强调痕迹。
6. 将必考点、高频考点和易错点同步标注到章节思维导图节点中。

### 第五步：题库生成

1. 生成章节练习题和答案解析。
2. 按难度分层（基础、常考、综合、迁移）。
3. 包含多种题型（选择、填空、简答、计算、案例等）。
4. 每道题附详细解析和常见错误。
5. 优先把资料中的例题、作业题、往年题和典型图表转换为题型原型。
6. 题库中可标注对应的思维导图分支，帮助学生回到知识结构中复盘。

### 第六步：主动回忆材料

1. 生成测试卡片（定义卡、对比卡、流程卡、应用卡等）。
2. 整理背诵提纲和考前速记清单。
3. 提供关键词串联记忆法和口诀。
4. 卡片应覆盖资料中的关键定义、公式、流程、图表、对比点、例题方法和易错点。
5. 测试卡片可按章节思维导图分支分组。

### 第七步：解题教练

1. 对计算题、算法题、病例题、案例题等补充分步解题过程。
2. 提供学科专属的分析模板。
3. 包含示例题和常见变形。
4. 解题模板应优先从上传资料中的例题、作业题、实验或往年题抽象得到。

### 第八步：模拟卷

1. 根据蓝图生成精准 100 分模拟卷。
2. 包含标准答案、评分 Rubric 和部分给分说明。
3. 提供考后诊断分析。
4. 题目覆盖比例应和上传资料的信息量、章节权重和考试范围相匹配。

### 第九步：输出整理

1. 按统一格式整理所有内容。
2. 如需要，生成 DOCX 版本。
3. 如需要，生成交互式测试卡片 HTML。
4. 输出前执行资料覆盖检查，确认没有明显遗漏重要单元、图表、公式、例题、流程或题型线索。
5. 检查课程总览和每章总览是否都有思维导图，且不是泛泛模板。

## 默认完整输出

完整期末复习资料应包含：

1. 课程总体框架
2. 学科大类和复习策略
3. 章节结构
4. 资料覆盖清单
5. 课程总览思维导图
6. 每章章节总览思维导图
7. 逐章复习讲义
8. 考点优先级排序
9. 关键定义和核心概念
10. 概念对比表、公式/规则表
11. 常见题型
12. 易错点
13. 章节题库
14. 测试卡片（可导出 CSV 和交互式 HTML）
15. 背诵提纲
16. 错题日志和薄弱点修复计划
17. 考前冲刺清单
18. 精准模拟卷（含评分 Rubric）

## 资料依据规则

优先依据用户上传的资料。如果某个内容不是资料中直接出现的，但属于必要背景知识，需要标注为"补充背景"。

标注规则：

- `来自上传资料`：直接从用户提供的材料中提取。
- `基于资料推测的考点`：根据资料内容推断的考试重点。
- `补充背景知识`：资料中没有但必要的背景信息。

## 信息保留规则

完整复习资料不是资料的极简摘要，而是对资料的结构化重写。必须遵守：

1. 覆盖用户上传或提到的所有章节、单元和主要小节。
2. 保留资料中的定义、公式、流程、算法、图表、例题、分类、实验步骤、案例、作业题和往年题线索。
3. 对图表、公式、例题不能只提一句，应转写为说明、表格、步骤、题型模板或思维导图节点。
4. 单元内容不得过短；如果某单元资料较多，讲义也应相应增加内容量。
5. 只压缩重复信息，不删除独立信息点。
6. 如果资料缺失或看不清，明确说明缺失范围。

## 思维导图规则

生成课程总览或章节总览时，使用 [`mind-map.md`](mind-map.md) 的规范。默认要求：

- 课程总览思维导图展示课程章节关系、主线、模块划分和考试权重。
- 章节总览思维导图展示本章标题层级、核心概念、公式/流程/算法/图表、例题和题型线索。
- 节点必须来自资料或根据资料结构推断，不能写泛泛模板。
- Markdown 默认优先使用 Mermaid `mindmap`，DOCX 默认使用可打印的层级框、缩进树或表格块。
- 思维导图必须服务复习，不追求装饰；重点是结构、关系、考点、易错点。

## 输出格式

根据用户需求选择输出格式：

- **Markdown**：默认格式，适合在线查看和编辑；思维导图优先使用 Mermaid `mindmap` 或缩进树。
- **DOCX/Word**：适合打印和分享，参考 [`docx-style-guide.md`](docx-style-guide.md)；思维导图使用层级框、缩进树、表格块或可读图片。
- **交互式 HTML**：测试卡片专用，参考 [`test-cards.md`](test-cards.md)。

## 多学科组合

当课程涉及多个学科领域时：

1. 确定主要学科和次要学科。
2. 用主要学科的模板为主。
3. 补充次要学科的专属内容。
4. 在交叉部分用组合模板。

例如：

- 医学伦理：医学/健康 + 法学/人文。
- 教育心理学：教育 + 社会科学。
- 商法：商科/经济 + 法学。
- 技术写作：计算机/工程 + 人文学科。
- 健康经济学：医学/健康 + 经管/经济。

## 质量检查清单

完成复习包后检查：

- [ ] 章节结构是否完整覆盖考试范围。
- [ ] 是否建立了资料覆盖清单。
- [ ] 是否生成了课程总览思维导图。
- [ ] 每章章节总览是否包含思维导图。
- [ ] 思维导图是否来自资料结构，是否覆盖主要小节、图表、公式、流程、例题和考点线索。
- [ ] 每章、每节是否能对应到上传资料或用户提到的资料。
- [ ] 概念定义是否准确、清晰。
- [ ] 公式和定理是否包含适用条件。
- [ ] 资料中的图、表、公式、流程、算法、例题、案例和作业题线索是否被保留。
- [ ] 是否存在内容过短、泛泛而谈、脱离资料的小节。
- [ ] 题库是否覆盖多种难度和题型。
- [ ] 答案解析是否足够详细。
- [ ] 易错点是否明确标注。
- [ ] 背诵提纲是否可直接使用。
- [ ] 模拟卷是否符合考试格式。
- [ ] 所有内容是否基于上传资料。
- [ ] 补充内容是否标注为"补充背景"。
