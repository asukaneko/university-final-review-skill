# 背诵提纲

这个模块适合需要直接背诵的章节或课程。目标是把复杂内容转化为可直接记忆和考试使用的结构化材料。

## 输出内容

每章建议包含：

1. 必背关键词
2. 必背定义
3. 简答题标准模板
4. 大题答题框架
5. 可以直接背的答案段落
6. 关键词串联记忆法
7. 易混概念对比表
8. 考前 30 分钟速记版

## 答题风格

对于理论类课程，答案应尽量接近期末考试卷面表达：

- 开头先给出定义或总观点。
- 中间使用分点展开。
- 结尾根据需要做一句总结。

## 记忆方法工具箱

### 1. 关键词串联法

把一章的核心关键词串联成一个故事或画面：

```
关键词：进程、线程、上下文切换、调度、死锁
串联画面：进程（工人）带着线程（工具）在车间（CPU）工作，
          调度员（调度算法）决定谁先用设备，
          如果两个工人互相等对方手里的工具，就死锁了。
```

### 2. 首字母缩略词

用每条要点的首字母组成一个有意义的词：

```
FIFO 调度：First In First Out → "先进先出"
STABLE 排序：Selection, Two-pointer, bubble, Insertion, linked-list, Counting → "STABLE"
```

### 3. 对比表格法

把易混概念放在表格中对比：

| 维度 | 概念 A | 概念 B |
| --- | --- | --- |
| 定义 | ... | ... |
| 特点 | ... | ... |
| 适用场景 | ... | ... |
| 常见错误 | ... | ... |

### 4. 框架填空法

先记住框架，再往里填内容：

```
病理生理框架：
危险因素 → 病因 → 发病机制 → 病理改变 → 临床表现 → 并发症 → 预后
```

### 5. 费曼简化法

用最简单的语言解释给一个外行听：

```
什么是 TCP 三次握手？
"打电话确认对方在听：你听得到吗？听到了。好的，那我说了。"
```

### 6. 时间线记忆法

把事件按时间顺序排列，标注关键节点：

```
软件开发模型：
需求分析 → 设计 → 编码 → 测试 → 部署 → 维护
```

### 7. 口诀/顺口溜法

把枯燥内容编成押韵的口诀：

```
进程状态：就绪、运行、阻塞、创建、终止
口诀："就运阻创终" → "就云阻创终"
```

### 8. 画面联想法

把抽象概念转化为生动画面：

```
数据库范式：
1NF（每个格子只有一个值）→ 一个格子放一颗糖
2NF（非主属性完全依赖主键）→ 所有糖都挂在主绳上
3NF（非主属性不传递依赖）→ 糖之间不能互相传递
```

## 学科专属背诵策略

### 思政 / 通识类

**特点**：大量定义、原理、意义、对策需要背诵。

**策略**：
- 先理解逻辑链条（为什么 → 是什么 → 怎么办）。
- 用"总—分—总"结构组织答案。
- 每个要点先背关键词，再扩展成句。
- 用表格对比相似概念（如"依法治国 vs 以德治国"）。
- 做"万能句式"积累：开头句、过渡句、总结句。

**速记版结构**：
```
一、核心定义（一句话）
二、主要特征（3-5 个关键词）
三、重要意义（对谁、什么意义）
四、实践要求（怎么做）
```

### 历史类

**特点**：时间线、事件因果、人物评价、意义分析。

**策略**：
- 用时间线串联事件（背景 → 经过 → 结果 → 影响）。
- 用表格对比相似事件或人物。
- 用"原因—过程—结果—意义"四段式组织答案。
- 重点背诵"转折点"和"标志性事件"。

### 计算机理论类

**特点**：概念定义、原理机制、算法步骤、协议规范。

**策略**：
- 用流程图或状态图辅助记忆。
- 用对比表区分相似概念（进程 vs 线程）。
- 用"输入—处理—输出"框架记忆算法。
- 用伪代码记忆协议步骤。

### 管理 / 经济理论类

**特点**：模型、框架、理论流派、政策影响。

**策略**：
- 用"假设—结论—局限"框架记忆理论。
- 用表格对比不同理论流派。
- 用图形辅助记忆供需曲线、SWOT 矩阵等。
- 用案例辅助记忆抽象理论。

```markdown
### 万能答题句式
- 开头：...
- 过渡：...
- 总结：...
```

## 考前 30 分钟速记清单

最后冲刺时，按以下顺序快速浏览：

1. **公式/规则表**（1 分钟/章）
2. **易错点清单**（30 秒/章）
3. **高频考点标记**（30 秒/章）
4. **速记版关键词**（1 分钟/章）
5. **万能答题句式**（整体 2 分钟）
