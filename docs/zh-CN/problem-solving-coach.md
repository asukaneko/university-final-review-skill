# 学科专属解题 / 分析教练

当课程不只是背诵，而是需要计算、证明、实验分析、法律案例分析、临床推理、数据解释、论述题写作、设计批评等学科专属解题能力时，使用本模块。

## 用途

本模块把原来的"计算题 / 算法题"工作流扩展为跨学科的问题求解框架。使用时应先判断课程所属学科大类，再选择对应的分析模板。

## 通用输出结构

每一种题型建议包含：

1. 题型名称
2. 适用学科和考试场景
3. 所需概念、规则、公式、方法或框架
4. 分步骤解题或分析流程
5. 示例题或案例
6. 常见变形
7. 易错点
8. 考试快速判断方法
9. 练习题
10. 详细答案或参考提纲

## 学科专属模板

### STEM / 工程技术

适用于计算题、推导题、证明题、算法题、代码阅读、系统设计和实验分析。

**解题框架**：

1. 重述输入、输出、约束和边界情况。
2. 选择数据结构或工程模型，并说明理由。
3. 给出算法或流程步骤。
4. 说明正确性：不变量、终止性或工程依据。
5. 分析复杂度、资源消耗和局限。
6. 用普通样例、边界样例、失败样例测试。

**算法题子模板**：

1. 理解问题：输入规模、数据类型、时间限制。
2. 暴力解法：先写出最简单的解法，分析复杂度。
3. 优化思路：能否用更好的数据结构或算法？
4. 编码实现：写出清晰的伪代码或代码。
5. 测试验证：用具体例子验证正确性。
6. 复杂度分析：时间 + 空间复杂度。

**系统设计题子模板**：

1. 需求分析：功能需求 + 非功能需求（性能、可扩展性、可靠性）。
2. 高层架构：主要组件和它们的职责。
3. 数据模型：数据库表设计、索引策略。
4. 核心流程：关键用例的执行路径。
5. 权衡分析：为什么选择这个方案，牺牲了什么。
6. 扩展考虑：如何应对增长。

**实验分析题子模板**：

1. 实验目的：要验证什么假设。
2. 实验设计：变量、对照组、测量方法。
3. 数据解读：图表、趋势、异常值。
4. 结论推断：数据支持什么结论。
5. 误差分析：可能的误差来源和改进方向。

**常见易错点**：
- 边界条件处理不当（空输入、最大值、负数）。
- 单位不统一或遗漏单位。
- 复杂度分析时遗漏额外空间。
- 系统设计时忽略瓶颈和扩展性。
- 实验分析时混淆相关和因果。

### 理学 / 数学 / 自然科学

适用于定理证明、公式推导、机制解释、图像解释和实验分析。

**定量科学题框架**：

1. 判断现象、系统和模型。
2. 列出已知、未知、单位、假设和常数。
3. 选择方程并说明适用性。
4. 能先符号求解就先符号求解。
5. 跟踪单位和有效数字。
6. 从物理/生物/化学意义解释结果。

**证明 / 定理题框架**：

1. 明确要证明什么。
2. 列出定义、假设和可用定理。
3. 选择策略：直接证明、反证、归纳、构造、反例。
4. 每一步写理由，而不只是代数变形。
5. 检查边界情况和结论。

**实验 / 数据题框架**：

1. 问题：要回答什么科学问题。
2. 假设：基于已有知识的预测。
3. 变量/对照：自变量、因变量、控制变量。
4. 方法：实验步骤和测量工具。
5. 数据模式：图表显示什么趋势。
6. 结论：数据是否支持假设。
7. 局限：实验的不足和改进方向。

**图像解释题框架**：

1. 识别图像类型（坐标图、谱图、显微图等）。
2. 标注坐标轴、单位、比例尺。
3. 描述关键特征（峰值、拐点、异常）。
4. 解释特征的科学含义。
5. 联系理论模型。

**常见易错点**：
- 符号/单位混淆（如把 mV 写成 V）。
- 证明中跳步或理由不充分。
- 有效数字处理不当。
- 图像解释时只描述不解释。
- 实验题中忽略对照组的作用。

### 医学 / 健康

适用于病例分析、疾病机制、药物推理、护理决策、公共卫生指标和预防策略。

**临床推理框架**：

1. 问题表征：主诉、现病史、关键发现。
2. 关键发现：阳性体征、阴性体征、红旗征。
3. 鉴别诊断：列出可能的诊断，按可能性排序。
4. 最可能解释：选择最符合所有发现的诊断。
5. 检查：需要什么检查来确认或排除。
6. 优先级：治疗的优先顺序。
7. 安全/红旗：必须立即处理的危险情况。
8. 患者友好解释：用通俗语言向患者解释。

**疾病机制题框架**：

1. 危险因素 → 病因 → 发病机制 → 病理改变 → 临床表现 → 并发症。
2. 每一步都要说明因果关系。
3. 标注哪些环节是考试常考点。

**药物推理题框架**：

1. 药物类别 → 作用机制 → 适应证 → 禁忌证 → 不良反应 → 监测 → 患者教育。
2. 比较相似药物的异同。
3. 注意药物相互作用。

**公共卫生 / 流行病学题框架**：

1. 人群 → 暴露/干预 → 结局 → 指标 → 偏倚/混杂 → 解释 → 政策意义。
2. 相关时计算发病率、患病率、风险比、优势比等。
3. 评估研究设计的效度和局限。

**特别安全提示**：
- 输出仅用于课程学习，不能作为医疗建议。
- 对不确定内容要提示核对课程资料和指南。
- 每个病例都要区分"题干直接给出"、"可以推断"和"不能得出"的信息。

**常见易错点**：
- 混淆相似疾病（如 1 型和 2 型糖尿病）。
- 漏掉红旗征（如胸痛的危险信号）。
- 药物不良反应记忆混淆。
- 流行病学指标计算错误。
- 护理优先级判断不当。

### 法学

适用于案例题、案例摘要、制度比较和规则适用题。

**IRAC / CRAC 模板**：

每个争点：

1. **Issue（争点）**：把法律争点写成问题。
2. **Rule（规则）**：陈述规则、要件和权威来源。
3. **Application（适用）**：把每个要件应用到具体事实。
4. **Conclusion（结论）**：得出有限度的结论。
5. 处理反方观点和不确定事实。
6. 相关时说明救济、抗辩或后果。

**论述题模板**：

使用：**中心论点 → 法律框架 → 权威依据 → 分析 → 反驳 → 评价 → 结论**。

好的法律论述题不是罗列规则，而是评价规则的政策、协调性、公平、效率、权利保护、机构能力和改革意义。

**案例分析进阶**：

当案例涉及多个争点时：

1. 先识别所有争点。
2. 按重要性或逻辑顺序排列。
3. 每个争点用完整的 IRAC。
4. 最后综合各争点得出整体结论。

**常见易错点**：
- 先下结论再找规则（应该先分析再结论）。
- 漏掉构成要件中的某个要素。
- 无依据断言（没有引用法条或案例）。
- 忽略反方观点。
- 结论过于绝对或过于模糊。

### 人文学科

适用于论述题、文本解读、历史解释和比较题。

**文本细读框架**：

使用：**观察 → 证据 → 技法/形式 → 意义 → 背景 → 对论点的重要性**。

1. 观察：这段文本/这幅图像有什么特征。
2. 证据：哪些具体细节支持你的观察。
3. 技法/形式：作者/艺术家使用了什么手法。
4. 意义：这些手法产生了什么效果。
5. 背景：在什么历史/文化/作者背景下理解。
6. 对论点的重要性：如何服务于整体论证。

**历史题框架**：

使用：**主张 → 时间线/背景 → 原因 → 证据 → 后果 → 史学争论 → 判断**。

1. 主张：你的核心论点是什么。
2. 时间线/背景：事件发生的时间和环境。
3. 原因：直接原因和深层原因。
4. 证据：用什么史料支持。
5. 后果：短期和长期影响。
6. 史学争论：不同历史学家的解释。
7. 判断：你支持哪种解释，为什么。

**哲学题框架**：

使用：**论点 → 论证重构 → 假设 → 反驳 → 回应 → 评价**。

1. 论点：哲学家的核心主张。
2. 论证重构：用清晰的逻辑重述论证。
3. 假设：论证依赖什么前提。
4. 反驳：有什么反对意见。
5. 回应：哲学家如何回应反驳。
6. 评价：你认为论证是否成立。

**常见易错点**：
- 复述情节而非分析。
- 无证据断言。
- 时代错置（用后世观念解释历史事件）。
- 比较空泛（只说"A 和 B 都很重要"）。
- 忽略文本细节。

### 社会科学

适用于理论应用、研究方法题、案例分析、政策分析和数据解释。

**理论应用框架**：

使用：**现象 → 相关理论 → 关键概念 → 证据/案例 → 解释 → 局限 → 替代理论**。

1. 现象：要解释什么社会现象。
2. 相关理论：哪些理论可以解释。
3. 关键概念：理论中的核心构念。
4. 证据/案例：支持理论的实证研究。
5. 解释：理论如何解释现象。
6. 局限：理论的不足和批评。
7. 替代理论：其他理论如何解释。

**研究方法题框架**：

使用：**研究问题 → 假设 → 变量 → 设计 → 样本 → 测量 → 伦理 → 效度威胁 → 解释**。

**政策 / 案例分析框架**：

使用：**问题 → 利益相关者 → 原因 → 证据 → 选项 → 取舍 → 建议 → 评估指标**。

**常见易错点**：
- 混淆相关和因果。
- 忽略研究方法的局限。
- 理论应用时只描述不分析。
- 政策分析时忽略利益相关者。
- 数据解释时混淆不同统计指标。

### 经管 / 经济

适用于模型应用、财务计算、会计分录、图像分析和案例决策。

**定量商科/经济题框架**：

1. 判断决策问题或模型。
2. 列出数据、假设、时间范围和单位/货币。
3. 分步骤应用公式。
4. 解释结果：对决策意味着什么。
5. 做敏感性或局限说明。
6. 如题目要求，给出建议。

**案例分析框架**：

使用：**情境 → 问题 → 证据 → 框架 → 选项 → 评价标准 → 建议 → 执行风险**。

**经济图形题框架**：

使用：**初始均衡 → 冲击/变化 → 曲线移动 → 新均衡 → 福利/分配影响 → 政策含义**。

**财务计算题要点**：

- NPV、IRR、盈亏平衡、比率分析。
- 注意现金流时点（期初 vs 期末）。
- 注意折现率的选择和含义。
- 敏感性分析：关键假设变化时结果如何变化。

**常见易错点**：
- 混淆利润和现金流。
- 图形移动方向错误（供给 vs 需求）。
- 比率公式分子分母颠倒。
- NPV 计算中现金流时点错误。
- 案例分析时建议缺乏可行性。

### 教育 / 艺术 / 设计

适用于教案分析、教学理论应用、作品批评、设计批评、作品集反思和创作过程说明。

**教案分析框架**：

使用：**学习者/情境 → 学习目标 → 活动 → 评价 → 差异化 → 理由 → 学习证据 → 改进**。

**设计 / 艺术批评框架**：

使用：**意图 → 背景/观众 → 形式元素 → 技法/材料 → 体验/功能 → 证据 → 判断 → 修改方向**。

**反思写作框架**：

使用：**经历 → 证据 → 解释 → 理论连接 → 发生了什么变化 → 下一步行动**。

**常见易错点**：
- 反思停留在描述层面。
- 批评缺乏具体证据。
- 忽视约束条件（用户需求、学习者差异、场地限制）。
- 理论和实践脱节。
- 评价标准不明确。

## 输出原则

不要把所有课程都硬套成计算题或算法题格式。应根据学科和考试任务选择最合适的推理结构。

## 跨学科综合题处理

当题目涉及多个学科领域时：

1. 先识别主要学科框架。
2. 标注需要跨学科知识的部分。
3. 用主要学科的模板为主，补充其他学科的视角。
4. 在答案中说明跨学科连接。

## 练习题设计原则

好的练习题应该：

1. 有明确的考查目标。
2. 有具体的事实或数据。
3. 有合理的难度梯度。
4. 有清晰的评分标准。
5. 有易错点提示。
6. 有答案解析和复习建议。
