# 学科专属解题 / 分析教练

当课程不只是背诵，而是需要计算、证明、实验分析、法律案例分析、临床推理、数据解释、论述题写作、设计批评等学科专属解题能力时，使用本模块。

## 用途

本模块把原来的“计算题 / 算法题”工作流扩展为跨学科的问题求解框架。使用时应先判断课程所属学科大类，再选择对应的分析模板。

## 通用输出结构

每一种题型建议包含：

1. 题型名称
2. 适用学科和考试场景
3. 所需概念、规则、公式、方法或框架
4. 分步骤解题或分析流程
5. 示例题或案例
6. 常见变形
7. 易错点
8. 考试快速判断方法
9. 练习题
10. 详细答案或参考提纲

## 学科专属模板

### STEM / 工程技术

适用于计算题、推导题、证明题、算法题、代码阅读、系统设计和实验分析。

应包含：

- 已知条件和目标结果
- 公式、定理、算法或设计规则
- 分步骤推导或执行过程
- 单位、假设和边界条件
- 复杂度、误差或性能分析

### 理学 / 数学 / 自然科学

适用于定理证明、公式推导、机制解释、图像解释和实验分析。

应包含：

- 定义、假设和变量
- 定律 / 定理 / 模型选择
- 推导、证明或机制链条
- 数据、图像或实验结果解释
- 误差来源和局限性

### 医学 / 健康

适用于病例分析、疾病机制、药物推理、护理决策、公共卫生指标和预防策略。

应包含：

- 关键症状、体征、指标和危险因素
- 机制或病理生理链条
- 诊断或分类逻辑
- 治疗、预防、护理或公共卫生原则
- 安全提示和考试陷阱

内容仅用于课程学习和考试复习，不能替代专业医学判断。

### 法学

适用于案例题、案例摘要、制度比较和规则适用题。

建议使用“争点—规则—适用—结论”结构：

- 争点
- 规则
- 适用
- 结论

必要时补充构成要件、例外情形、证明标准或常见陷阱。

### 文史哲 / 语言文学

适用于论述题、文本解读、历史解释和比较题。

应包含：

- 中心论点
- 背景
- 证据或文本细节
- 分析
- 比较或反驳
- 结论提纲

### 社会科学

适用于理论应用、研究方法题、案例分析、政策分析和数据解释。

应包含：

- 理论或概念
- 方法、变量、证据或案例
- 分析链条
- 替代解释
- 局限性
- 政策或社会含义

### 经管 / 经济

适用于模型应用、财务计算、会计分录、图像分析和案例决策。

应包含：

- 模型或框架
- 假设条件
- 计算过程或案例事实
- 结果解释
- 决策建议
- 风险和局限

内容仅用于课程学习和考试复习，不构成财务、投资或经营建议。

### 教育 / 艺术 / 设计

适用于教案分析、教学理论应用、作品批评、设计批评、作品集反思和创作过程说明。

应包含：

- 理论、风格、方法或设计原则
- 背景和目标
- 来自教案、作品或项目的证据
- 分析和评价
- 改进建议或反思提纲

## 输出原则

不要把所有课程都硬套成计算题或算法题格式。应根据学科和考试任务选择最合适的推理结构。
