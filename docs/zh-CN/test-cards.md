# 测试卡片

测试卡片用于把复习笔记转化为可反复练习的主动回忆材料。测试卡片不是摘要卡，而是用问题迫使学生回忆、应用、比较或解释。

## 什么时候生成测试卡片

用户提出以下需求时应生成测试卡片：

- 闪卡；
- 记忆卡；
- 主动回忆卡；
- Anki 风格复习材料；
- 考前快速复习；
- 完整期末复习包。

如果用户要求“完整复习包”，默认包含测试卡片，除非用户明确要求简短输出。

## 卡片类型

应混合使用以下卡片类型。

### 1. 定义卡

```markdown
**正面：** 什么是【概念】？
**背面：** 【精确定义】+【一个例子】+【一个反例或对比概念】。
**标签：** 章节、概念、基础
```

### 2. 填空卡

```markdown
**题干：** 在【模型/过程】中，_____ 会在 _____ 条件下导致 _____。
**答案：** 【缺失术语或关系】
**为什么重要：** 【考试相关性】
```

### 3. 对比卡

```markdown
**正面：** 比较【A】和【B】。
**背面：**
| 维度 | A | B |
| --- | --- | --- |
| 定义 | ... | ... |
| 适用场景 | ... | ... |
| 常见考试陷阱 | ... | ... |
```

### 4. 流程 / 机制卡

```markdown
**正面：** 说明【过程/机制/算法】的步骤。
**背面：**
1. ...
2. ...
3. ...
**失分点：** 【学生常丢分的位置】
```

### 5. 公式 / 规则卡

```markdown
**正面：** 什么时候、如何使用【公式/规则/测试标准】？
**背面：**
- 公式/规则：...
- 符号/要件：...
- 适用前提：...
- 示例：...
- 不能使用的情况：...
```

### 6. 应用卡

```markdown
**正面：** 给定【迷你案例/问题】，第一步应该做什么，为什么？
**背面：** 【带理由的答案：第一步、规则/模型、解释】
```

### 7. 纠错卡

```markdown
**正面：** 某同学回答：“……” 错在哪里？
**背面：** 【错误诊断】→【正确推理】→【预防提示】
```

### 8. 迁移卡

```markdown
**正面：** 如果【条件变化】，【概念/方法】会如何变化？
**背面：** 【迁移推理和变化后的结论】
```

## 学科专属卡片建议

- **计算机 / 工程：** 公式卡、算法追踪卡、调试卡、单位检查卡、设计取舍卡。
- **自然科学 / 数学：** 定理条件卡、证明步骤卡、图像解释卡、实验对照卡。
- **医学 / 健康：** 疾病脚本卡、药物安全卡、红旗征卡、化验解释卡、临床推理卡。
- **法学：** 构成要件卡、案例规则卡、争点触发卡、IRAC 应用卡、反方观点卡。
- **人文学科：** 论点卡、证据卡、引文分析卡、时间线卡、解释争论卡。
- **社会科学：** 理论卡、方法效度卡、变量测量卡、案例应用卡、批判卡。
- **商科 / 经济：** 框架选择卡、计算建模卡、图形移动卡、比率解释卡、案例建议卡。
- **教育 / 艺术 / 设计：** 原则-例子卡、批评词汇卡、教案卡、作品集证据卡、反思卡。

## 卡片质量规则

好的测试卡片应当：

- 只测试一个主要知识点；
- 不打开笔记也能作答；
- 有简短解释，而不只是关键词；
- 必要时加入对比、例子或陷阱；
- 按章节、主题、难度和卡片类型打标签；
- 避免“解释第 3 章”这种空泛题干。

## 推荐输出格式

```markdown
## 测试卡片：第 N 章

### 基础回忆卡

| ID | 正面 | 背面 | 标签 |
| --- | --- | --- | --- |
| C1-01 | ... | ... | ch1;definition;basic |

### 应用卡

| ID | 正面 | 背面 | 标签 |
| --- | --- | --- | --- |
| C1-08 | ... | ... | ch1;application;exam |

### 纠错卡

| ID | 正面 | 背面 | 标签 |
| --- | --- | --- | --- |
| C1-13 | ... | ... | ch1;mistake;transfer |
```

## 数量建议

每章建议：

- 短章节：8-12 张；
- 普通章节：15-25 张；
- 考试密集章节：30-45 张；
- 最后冲刺套卡：全课程 50-120 张，按考点概率和学生薄弱点排序。

## 导出建议

用户要求 Anki/CSV 风格输出时，使用以下列：

```text
ID,Front,Back,Chapter,Topic,Difficulty,CardType,Tags
```

## 生成 HTML 复习界面

仓库提供零依赖脚本，可把测试卡 CSV 转换成单文件 HTML 复习界面：

```bash
python scripts/generate_test_cards_html.py \
  --input examples/test_cards.sample.csv \
  --output output/test_cards.html \
  --title "大学期末复习测试卡" \
  --language zh-CN
```

生成的 HTML 可以离线打开，适合交给学生直接复习。

### 支持的 CSV 字段

推荐字段：

```text
ID,Front,Back,Chapter,Topic,Difficulty,CardType,Tags
```

脚本也支持常见中文表头别名，例如：

- `正面` → `Front`
- `背面` / `答案` / `解析` → `Back`
- `章节` → `Chapter`
- `主题` / `知识点` → `Topic`
- `难度` → `Difficulty`
- `卡片类型` / `类型` → `CardType`
- `标签` → `Tags`

### HTML 界面功能

- 搜索题干、答案、主题和标签；
- 按章节、难度、卡片类型筛选；
- 翻卡显示答案；
- 使用 `1/2/3/4` 标记“不会 / 困难 / 掌握 / 熟练”；
- 自动记录复习次数、掌握分数和最后复习时间；
- “只看错题/困难”模式；
- 随机排序；
- 导出学习记录 CSV；
- 浏览器本地 `localStorage` 保存进度；
- 快捷键：空格翻卡，左右方向键切换卡片。

### 生成测试卡 CSV 的建议

在完整复习包中，先生成 CSV，再生成 HTML：

1. 按章节生成测试卡；
2. 每张卡只测试一个知识点；
3. 给每张卡标注章节、主题、难度、类型和标签；
4. 使用 `generate_test_cards_html.py` 生成可交互复习界面；
5. 让学生先做全部卡片，再用“只看错题/困难”进行二轮复习。
