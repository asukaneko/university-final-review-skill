# 计算题 / 算法题教练

这个模块适合包含计算、推导、调度、数据库、网络或算法题的技术类课程。

## 每类题输出结构

每一种题型建议包含：

1. 题型名称
2. 适用场景
3. 核心公式、规则或算法
4. 解题步骤
5. 手算过程示例
6. 常见变形
7. 易错点
8. 考试快速判断方法
9. 练习题
10. 详细答案

## 算法题专项要求

对于算法题，建议包含：

- 核心思想
- 伪代码
- C++ 实现
- 时间复杂度
- 空间复杂度
- 正确性直觉
- 与相似算法的区别

## 示例主题

- CPU 调度
- 页面置换
- 内存分配
- Master 定理
- 排序算法
- 图算法
- 数据库范式
- 关系代数
- TCP/IP 相关计算
