# 题库生成

本模块用于根据课程资料生成章节练习题、测试卡片、诊断练习和考试风格模拟题。

主动回忆闪卡请同时使用 [`test-cards.md`](test-cards.md)。完整模拟卷请同时使用 [`precision-mock-exam.md`](precision-mock-exam.md)。

## 题库层级

完整题库应包含四层：

1. **基础记忆**：定义、术语、公式、规则、日期、人物、组成部分。
2. **概念理解**：解释机制、比较概念、解读图示、识别假设。
3. **应用和流程**：计算、算法、案例、证明、数据解释、法律适用、设计批评。
4. **综合和迁移**：混合章节题、陌生情境、高分综合题。

## 必要题型

每章应根据学科选择合适题型：

- 单选题；
- 适合时生成多选题；
- 判断题并要求改正；
- 填空题或 cloze 题；
- 名词解释和概念比较；
- 简答解释题；
- 计算、证明、算法、代码、实验或数据题；
- 案例、临床、法律、商业、政策、作文、设计或批评题；
- 纠错题；
- 迁移题。

## 标准题型格式

生成题库时，每种题型使用以下统一格式：

### 单选题格式

```markdown
**QN-01**【基础 | 2 分钟 | 主题 | X 分】

【题干内容】（  ）

A. 【选项 A】

B. 【选项 B】

C. 【选项 C】

D. 【选项 D】

**答案：** X

**解析：** 【简要解析，说明为什么选 X，其他选项为什么错】

**常见错误：** 【学生常选错的选项及原因】

**复习提示：** 【一句话记忆要点】
```

### 填空题格式

```markdown
**QN-02**【基础 | 1 分钟 | 主题 | X 分】

【题干内容，含______空格】。

**答案：** 【标准答案】

**解析：** 【解题思路和关键点】

**常见错误：** 【常见错误填写】

**复习提示：** 【一句话记忆要点】
```

### 判断题格式

```markdown
**QN-03**【基础 | 1 分钟 | 主题 | X 分】

【陈述内容】（  ）

**答案：** ✓ / ✗

**判断依据：** 【引用知识点或条文】

**解析：** 【为什么对/错】

**常见错误：** 【常见误判及原因】

**复习提示：** 【一句话记忆要点】
```

### 名词解释格式

```markdown
**QN-04**【基础 | 3 分钟 | 主题 | X 分】

**【术语名称】**

**答案：** 【标准定义，2-4 句话】

**评分标准：** 关键词"XX"（X 分），核心概念"XX"（X 分），举例说明（X 分）

**常见错误：** 【定义不完整、遗漏关键要素】

**复习提示：** 【记忆口诀或关键词】
```

### 简答题格式

```markdown
**QN-05**【常考 | 5 分钟 | 主题 | X 分】

**【问题内容】**

**参考答案：**

1. 【要点 1】（X 分）
2. 【要点 2】（X 分）
3. 【要点 3】（X 分）

**评分标准：**

| 评分项 | 分值 | 给分条件 |
| --- | ---: | --- |
| 要点 1 | X | 准确答出…… |
| 要点 2 | X | 完整说明…… |
| 要点 3 | X | 正确解释…… |

**常见错误：**
- 错误 1：……（扣 X 分）
- 错误 2：……（扣 X 分）

**复习提示：** 【答题框架或关键词】
```

### 计算/分析题格式

```markdown
**QN-06**【综合 | 10 分钟 | 主题 | X 分】

**【题目内容，含具体数据/案例/材料】**

**解题过程：**

1. 【第一步】
   - 公式/依据：……
   - 计算/分析：……
   - 得分：X 分

2. 【第二步】
   - ……

**最终答案：** 【带单位/格式的最终结果】

**评分标准：**

| 评分项 | 分值 | 给分条件 |
| --- | ---: | --- |
| 模型/公式选择 | X | 正确识别…… |
| 计算过程 | X | 步骤完整，单位正确…… |
| 结果解释 | X | 合理解释含义…… |
| 答案表达 | X | 格式规范，结论明确…… |

**常见错误：**
- 错误 1：……（扣 X 分）
- 错误 2：……（扣 X 分）

**复习提示：** 【解题关键步骤】
```

### 案例/论述题格式

```markdown
**QN-07**【迁移 | 15 分钟 | 主题 | X 分】

**【完整案例/材料背景】**

**【问题要求】**

**参考答案：**

【完整、结构化的答案】

**评分标准：**

| 评分项 | 分值 | 给分条件 |
| --- | ---: | --- |
| 分析框架 | X | 正确运用…… |
| 证据使用 | X | 充分引用…… |
| 逻辑推理 | X | 推理严密，论证充分…… |
| 结论质量 | X | 结论合理，有深度…… |

**部分给分说明：**
- 只答出部分要点：按比例给分
- 框架正确但内容不全：给框架分
- 有创新见解但偏离主题：酌情给分

**常见错误：**
- 错误 1：……（扣 X 分）
- 错误 2：……（扣 X 分）

**复习提示：** 【答题框架和关键要素】
```

## 每道题必须包含的元数据

每道题建议包含：

- 题目 ID；
- 章节和主题；
- 对应学习目标；
- 题型；
- 难度（基础/常考/综合/迁移）；
- 预计用时；
- 如果是考试题，标注分值；
- 正确答案；
- 详细解析；
- 评分标准（简答及以上题型）；
- 来源依据：来自上传资料 / 基于资料推断的考点 / 补充背景知识；
- 常见错误；
- 复习提示；
- 必要时附后续复习卡片。

## 难度等级

使用四档：

1. **基础题**：直接记忆或一步识别。
2. **常考题**：标准解释或常规应用。
3. **综合提高题**：多步推理或跨章节联系。
4. **迁移题**：陌生案例、条件变化或综合判断。

## 每章题量建议

普通章节建议生成：

- 5-8 道基础记忆题；
- 5-8 道概念理解题；
- 4-6 道应用/流程题；
- 2-4 道综合或迁移题；
- 8-25 张测试卡片，按章节密度调整。

考试密集章节应增加应用题和迁移题比例。

## 答案质量要求

答案应展示：

- 最终答案；
- 推理路径；
- 为什么该方法/规则适用；
- 为什么常见替代答案错误；
- 相关时给出部分得分点；
- 一句便于记忆的复习提示。

## 与模拟卷的连接

如果用户要求模拟卷，不要随机抽题。应根据 [`precision-mock-exam.md`](precision-mock-exam.md) 先建立蓝图，再按章节权重分配分值、平衡认知层级，并提供评分 Rubric。

模拟卷的题目应从题库中按蓝图选取，或按题库格式标准新命题。确保：
- 题号连续、无遗漏；
- 分值分配合理；
- 题型覆盖全面；
- 难度梯度适当。
