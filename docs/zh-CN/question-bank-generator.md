# 题库生成

本模块用于根据课程资料生成章节练习题、测试卡片、诊断练习和考试风格模拟题。

主动回忆闪卡请同时使用 [`test-cards.md`](test-cards.md)。完整模拟卷请同时使用 [`precision-mock-exam.md`](precision-mock-exam.md)。

## 题库层级

完整题库应包含四层：

1. **基础记忆**：定义、术语、公式、规则、日期、人物、组成部分。
2. **概念理解**：解释机制、比较概念、解读图示、识别假设。
3. **应用和流程**：计算、算法、案例、证明、数据解释、法律适用、设计批评。
4. **综合和迁移**：混合章节题、陌生情境、高分综合题。

## 必要题型

每章应根据学科选择合适题型：

- 单选题；
- 适合时生成多选题；
- 判断题并要求改正；
- 填空题或 cloze 题；
- 名词解释和概念比较；
- 简答解释题；
- 计算、证明、算法、代码、实验或数据题；
- 案例、临床、法律、商业、政策、作文、设计或批评题；
- 纠错题；
- 迁移题。

## 每道题必须包含的元数据

每道题建议包含：

- 题目 ID；
- 章节和主题；
- 对应学习目标；
- 题型；
- 难度；
- 预计用时；
- 如果是考试题，标注分值；
- 正确答案；
- 详细解析；
- 来源依据：来自上传资料 / 基于资料推断的考点 / 补充背景知识；
- 常见错误；
- 必要时附后续复习卡片。

## 难度等级

使用四档：

1. **基础题**：直接记忆或一步识别。
2. **常考题**：标准解释或常规应用。
3. **综合提高题**：多步推理或跨章节联系。
4. **迁移题**：陌生案例、条件变化或综合判断。

## 每章题量建议

普通章节建议生成：

- 5-8 道基础记忆题；
- 5-8 道概念理解题；
- 4-6 道应用/流程题；
- 2-4 道综合或迁移题；
- 8-25 张测试卡片，按章节密度调整。

考试密集章节应增加应用题和迁移题比例。

## 答案质量要求

答案应展示：

- 最终答案；
- 推理路径；
- 为什么该方法/规则适用；
- 为什么常见替代答案错误；
- 相关时给出部分得分点；
- 一句便于记忆的复习提示。

## 输出格式

```markdown
## 第 N 章题库

### 蓝图

| 主题 | 权重 | 题型 | 难度重点 |
| --- | ---: | --- | --- |

### 题目

#### QN-01【基础 | 2 分钟 | 主题】
题干……

**答案：** ...
**解析：** ...
**常见错误：** ...
**复习提示：** ...
```

## 与模拟卷的连接

如果用户要求模拟卷，不要随机抽题。应根据 [`precision-mock-exam.md`](precision-mock-exam.md) 先建立蓝图，再按章节权重分配分值、平衡认知层级，并提供评分 Rubric。
