# 精准模拟卷蓝图

本模块用于生成准确、贴近真实考试的模拟卷，而不是泛泛的练习题。精准模拟卷应反映课程资料、考核风格、主题权重、认知层级和评分逻辑。

## 必要输入

尽量使用所有可用证据：

- 教学大纲和官方考试范围；
- PPT、讲义、课堂笔记；
- 作业、实验、习题课、小测；
- 往年题和参考答案；
- 老师强调内容和反复使用的例子；
- 用户提供的考试题型、时长和总分。

如果考试格式未知，可以推断一个合理默认格式，但必须明确标注"基于资料推断"。

## 试卷蓝图表

写题前先生成蓝图：

| 主题 / 章节 | 证据来源 | 预计权重 | 认知层级 | 题型 | 分值 |
| --- | --- | ---: | --- | --- | ---: |
| 第 1 章 | PPT + 作业 | 15% | 记忆 + 应用 | 选择 + 简答 | 15 |

## 认知层级比例

除非课程证据显示应调整，否则建议：

- 20-30% 记忆和识别；
- 25-35% 解释和概念理解；
- 25-35% 应用、计算、案例、证明或分析；
- 10-20% 综合、评价、设计或迁移。

## 精准命题规则

每道题都应标明：

- 来源主题或章节；
- 对应学习目标；
- 难度；
- 预计用时；
- 分值；
- 作答格式；
- 评分点；
- 常见陷阱。

避免"讨论第 4 章"这种空泛问题。题目必须具体、可评分。

## 默认 100 分结构

用户未提供格式时，使用：

1. **A 部分：快速记忆和概念检查** — 20 分。
2. **B 部分：简答解释题** — 25 分。
3. **C 部分：应用题 / 案例题 / 计算题 / 分析题** — 35 分。
4. **D 部分：综合高分题** — 20 分。

按学科调整结构：

- 计算机/工程：加入计算、算法、推导、调试或设计。
- 自然科学：加入机制、数据解释、证明、实验设计。
- 医学：加入病例、化验解释、安全和临床推理。
- 法学：加入争点识别案例、规则适用、政策论述。
- 人文学科：加入证据型作文、细读、比较。
- 社会科学：加入理论应用、方法批判、数据/案例分析。
- 商科：加入计算、图形、案例建议、管理备忘录。
- 教育/艺术/设计：加入批评、教案/设计任务、反思、作品集说明。

## 学科专属试卷调整

### 计算机/工程

- 选择题：概念辨析、算法复杂度、协议步骤
- 填空题：公式参数、算法步骤、数据结构特性
- 计算题：时间复杂度计算、电路分析、SQL 查询
- 代码题：补全代码、调试纠错、算法设计
- 设计题：系统架构、数据库设计、算法选型

### 自然科学/数学

- 选择题：概念判断、公式适用条件
- 填空题：公式推导、定理条件
- 证明题：定理证明、不等式推导
- 计算题：公式代入、数值计算
- 实验题：数据解释、实验设计

### 医学/健康

- 选择题：疾病特征、药物机制、检查选择
- 填空题：解剖结构、实验室值、诊断标准
- 病例题：完整病例分析、临床推理
- 机制题：病理生理过程、药物作用机制
- 公共卫生题：流行病学指标计算、干预措施

### 法学

- 选择题：法律概念、构成要件判断
- 填空题：法条关键词、构成要件
- 案例分析题：争点识别、IRAC 适用
- 条文解释题：法条含义、适用范围
- 论述题：法律原则评价、政策分析

### 人文学科

- 选择题：概念辨析、背景知识
- 填空题：关键术语、时间/人物
- 简答题：概念解释、比较分析
- 细读题：文本/图像分析
- 论述题：论证作文、比较研究

### 社会科学

- 选择题：理论判断、概念辨析
- 填空题：理论家、核心概念
- 简答题：理论比较、概念解释
- 案例分析：理论应用、政策分析
- 方法题：研究设计、效度分析

### 商科/经济

- 选择题：概念判断、框架适用
- 填空题：公式、比率定义
- 计算题：NPV、比率、弹性计算
- 图形分析：供需曲线、均衡变化
- 案例分析：商业诊断、战略建议

### 教育/艺术/设计

- 选择题：理论判断、原则应用
- 填空题：关键术语、理论家
- 教案分析：教学设计评价
- 设计批评：作品分析、改进建议
- 反思写作：经历→理论→改进

## 答案要求

答案部分必须包含：

- 正确答案；
- 推理步骤；
- 分值分配；
- 可接受替代表达；
- 常见错误答案及其错误原因；
- 来源主题引用；
- 部分给分说明。

## Rubric 格式

```markdown
### 第 X 题评分标准：【分值】

| 评分项 | 分值 | 满足什么条件给分 |
| --- | ---: | --- |
| 正确选择规则/模型 | 2 | 学生识别出…… |
| 应用于事实/数据 | 4 | 学生使用…… |
| 解释/评价 | 2 | 学生说明…… |
```

## 模拟卷变体

必要时生成多个版本：

- **A 版：最可能考试风格** — 最贴近预期格式。
- **B 版：高难迁移版** — 测陌生案例和迁移能力。
- **C 版：快速诊断版** — 更短，用于定位薄弱章节。

## 校准清单

定稿前检查：

- 总分是否等于 100。
- 时间是否现实。
- 主要章节是否按权重覆盖。
- 题目是否符合学科和考试风格。
- 题干中是否泄露答案。
- 答案是否足够具体，便于自我批改。
- 至少包含一道综合题。
- 试卷格式是否统一、规范。
- 答案与试卷题号是否一一对应。
- 评分标准是否可操作、可量化。

## 生成 DOCX 模拟卷

生成标准化模拟卷 DOCX 时，使用以下流程：

### 第一步：生成 JSON 数据

按以下格式组织模拟卷数据：

```json
{
  "metadata": {
    "course": "课程名称",
    "exam_title": "期末模拟试卷",
    "duration": "120 分钟",
    "total_marks": 100,
    "mode": "闭卷",
    "orientation": "landscape",
    "version": "A",
    "header": "页眉文字",
    "footer": "页脚文字",
    "instructions": ["注意事项 1", "注意事项 2"]
  },
  "sections": [
    {
      "title": "一、选择题",
      "description": "每题只有一个正确答案",
      "total_marks": 20,
      "page_break_before": true,
      "questions": [...]
    }
  ],
  "answers": [...],
  "diagnosis": {...}
}
```

### metadata 字段说明

| 字段 | 必填 | 说明 |
| --- | --- | --- |
| course | 是 | 课程名称 |
| exam_title | 否 | 试卷标题，默认"期末模拟试卷" |
| duration | 是 | 考试时长 |
| total_marks | 是 | 满分 |
| mode | 否 | 考试形式：闭卷/开卷 |
| orientation | 否 | 页面方向：landscape（横页）或 portrait（竖页），默认 landscape |
| version | 否 | 试卷版本，默认 A |
| header | 否 | 页眉文字 |
| footer | 否 | 页脚文字 |
| instructions | 否 | 注意事项列表 |

### sections 字段说明

每个 section 包含：

| 字段 | 必填 | 说明 |
| --- | --- | --- |
| title | 是 | 大题标题，如"一、选择题" |
| description | 否 | 题型说明 |
| total_marks | 是 | 本大题总分 |
| page_break_before | 否 | 是否在本大题前分页，默认 true |
| questions | 是 | 题目列表 |

### questions 字段说明

每个 question 包含：

| 字段 | 必填 | 说明 |
| --- | --- | --- |
| number | 是 | 题号 |
| type | 否 | 题型：单选/填空/判断/名词解释/简答/计算/分析/综合 |
| text | 是 | 题干内容 |
| marks | 是 | 分值 |
| time | 否 | 预计用时 |
| options | 否 | 选择题选项列表 |
| sub_questions | 否 | 子题目列表 |
| answer_lines | 否 | 答题空白行数 |
| page_break_before | 否 | 是否在本题前强制分页 |

### 第二步：运行脚本生成 DOCX

```bash
python scripts/generate_mock_exam_docx.py \
  --input examples/mock_exam_os.sample.json \
  --output output/mock_exam_os.docx
```

### 页面布局

- **横页（landscape）**：页面宽度 29.7cm，高度 21.0cm，适合选择题多、题干较长的试卷。
- **竖页（portrait）**：页面宽度 21.0cm，高度 29.7cm，适合简答论述为主的试卷。

### 分页规则

- 每个大题（section）前自动分页。
- 题目标题和题干使用 keep_with_next，防止题目被分到两页。
- 选项之间使用 keep_with_next，防止选项被分开。
- 答案部分和诊断分析部分前自动分页。
