# 社会科学

适用于社会学、心理学、政治学、国际关系、传播学、人类学、犯罪学、社会政策和研究方法课程。

## 复习目标

连接理论、概念、方法、实证发现、案例和政策含义，使学生能解释社会现象并评价证据。

## 需要从材料中提取什么

- 理论、理论家、模型、构念、变量、假设和机制。
- 研究设计、抽样、测量、效度、信度、伦理和统计解释。
- 实证发现、案例、政策例子、历史背景和比较证据。
- 课堂争论、批判点和方法局限。
- 作文、报告、案例分析或数据解释的评分标准。

## 每章笔记结构

1. **核心社会问题**：要解释什么现象。
2. **理论图**：理论家、假设、因果机制、预测。
3. **概念定义**：构念、维度、测量指标。
4. **证据总结**：研究、案例、数据模式、局限。
5. **方法要点**：设计、样本、测量、效度、伦理。
6. **应用例子**：政策、组织、媒体、社区、跨文化案例。
7. **比较表**：理论或方法并列比较。
8. **批判库**：优点、缺点、偏差、可推广性。
9. **作文/案例模板**。
10. **练习题**。

## 常见题型

- 定义概念并比较理论。
- 把理论应用到案例、政策、事件或数据。
- 评价实证证据和研究方法。
- 解读统计、图表、问卷结果或访谈摘录。
- 关于争论、原因、后果或干预写作文。
- 设计小型研究并说明方法选择。

## 分析模板

### 理论应用

使用：**现象 → 相关理论 → 关键概念 → 证据/案例 → 解释 → 局限 → 替代理论**。

### 研究方法题

使用：**研究问题 → 假设 → 变量 → 设计 → 样本 → 测量 → 伦理 → 效度威胁 → 解释**。

### 政策 / 案例分析

使用：**问题 → 利益相关者 → 原因 → 证据 → 选项 → 取舍 → 建议 → 评估指标**。

## 题库生成规则

建议比例：

- 20% 概念和理论家记忆。
- 25% 理论比较与应用。
- 25% 研究方法/数据解释。
- 20% 案例或政策分析。
- 10% 综合作文题。

答案要包含证据和局限，而不只是理论描述。

## 高频考点预测信号

优先关注：

- 多次课程中作为核心框架出现的理论。
- 与经典研究、标志性案例或政策争论相关的内容。
- 涉及方法、效度、伦理或数据解释的内容。
- 能应用到当前或陌生例子的内容。

## 主动复习方法

- 做理论卡：假设、机制、证据、批评、例子。
- 用同一个案例练习套用多种理论。
- 重画研究设计并识别效度威胁。
- 用间隔复习记理论家、构念和研究发现。
- 针对高频作文动词写限时段落提纲。

## 评分 Rubric

给分点包括：概念准确性、理论与案例匹配、证据使用、方法意识、批判、平衡判断和结构清晰。
