# 医学 / 护理 / 药学 / 公共卫生

适用于基础医学、临床医学、护理学、药学、公共卫生、解剖学、生理学、病理学、微生物学等医学健康类课程。

## 复习重点

- 解剖结构、生理机制、病理过程和药理机制
- 疾病定义、病因、发病机制、临床表现、诊断、治疗原则和预防
- 临床推理链条和鉴别诊断思路
- 禁忌证、不良反应、剂量概念、护理注意事项等安全性细节
- 公共卫生框架、流行病学指标、预防策略和卫生政策概念

## 每章推荐结构

1. 核心术语和正常结构 / 功能
2. 机制或疾病过程
3. 关键症状、体征、检查指标和危险因素
4. 诊断或分类逻辑
5. 治疗、预防、护理或公共卫生干预原则
6. 临床案例分析模板
7. 高危易错点和安全提示
8. 练习题和解析

## 常见题型

- 名词解释和术语辨析
- 结构与功能匹配
- 机制解释题
- 病例分析题
- 鉴别诊断或临床推理题
- 药物机制、不良反应和禁忌证题
- 公共卫生指标计算或解释题

## 安全说明

输出只用于课程学习和考试复习，不能替代专业诊断、治疗、用药或临床决策。
