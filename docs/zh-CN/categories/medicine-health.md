# 医学 / 健康科学

适用于医学、护理、药学、口腔、公共卫生、流行病学、解剖、生理、病理、药理、临床技能和相关健康科学课程。

## 安全边界

输出仅用于课程学习，不能作为医疗建议、诊断、治疗方案或专业指导替代。对不确定内容要提示核对课程资料、指南和老师认可来源。

## 复习目标

帮助学生连接正常结构/功能、疾病机制、临床表现、检查、处理原则、用药安全、公共卫生推理和考试式临床思维。

## 需要从材料中提取什么

- 解剖、生理、病理、微生物、药理和临床技能框架。
- 疾病定义、病因、危险因素、机制、症状体征、红旗征、检查和处理原则。
- 药物类别、机制、适应证、禁忌证、不良反应、相互作用、监测和宣教点。
- 临床病例、OSCE 清单、护理计划、流行病学指标和公共卫生干预。
- 图示、表格、通路、实验室数值、影像描述和课程给出的指南摘要。

## 每章笔记结构

1. **系统或疾病总览**。
2. **正常基础**：解剖/生理或公共卫生背景。
3. **病理生理/机制**：从危险因素到表现的因果链。
4. **临床表现**：关键症状、体征、红旗和鉴别线索。
5. **检查**：每项检查看什么，典型模式如何解释。
6. **处理原则**：学习层面的选择、优先级和安全关注。
7. **药理表**：机制、用途、不良反应、禁忌、监测。
8. **病例推理模板**：评估、优先事项、理由、下一步。
9. **常见错误**：混淆相似疾病、漏掉红旗、不安全假设。
10. **病例题和简答题**。

## 常见题型

- 解剖/生理标注和机制解释。
- 比较相似疾病、药物、病原体或公共卫生措施。
- 解读实验室值、生命体征、流行病学数据或病例描述。
- 解释从病因到症状的病理生理过程。
- 药理机制、不良反应、禁忌证问题。
- 护理优先级、患者教育、伦理、安全和升级处理。
- OSCE 站点计划或临床沟通。

## 临床推理模板

使用：**问题表征 → 关键发现 → 鉴别诊断 → 最可能解释 → 检查 → 优先级 → 安全/红旗 → 患者友好解释**。

每个病例要区分：

- 题干直接给出的信息。
- 根据题干推断的信息。
- 不能从题干得出的结论。
- 不应做出的不安全假设。

## 公共卫生 / 流行病学模板

使用：**人群 → 暴露/干预 → 结局 → 指标 → 偏倚/混杂 → 解释 → 政策意义**。

相关时加入发病率、患病率、风险比、优势比、敏感度、特异度、阳性预测值、阴性预测值和置信区间。

## 题库生成规则

建议比例：

- 20% 解剖、生理、药物、定义等事实记忆。
- 25% 机制/病理生理解释。
- 25% 病例和临床推理。
- 15% 检查/数据解释。
- 15% 安全、伦理、沟通、公共卫生或用药问题。

答案要有理由和安全提示，而不只是正确选项。

## 高频考点预测信号

优先关注：

- 常见、危险、容易考或病例/OSCE 中强调的内容。
- 能把基础科学和临床表现连接起来的内容。
- 涉及用药安全或红旗征的内容。
- 出现在表格、流程图、指南摘要或重复病例模式中的内容。

## 主动复习方法

- 用空白页默写疾病脚本：定义、机制、表现、检查、处理原则、安全。
- 用表格比较相似疾病。
- 限时练病例并口头说出推理链。
- 用间隔复习记解剖、药物类别、实验室值和诊断标准。

## 评分 Rubric

给分点包括：知识准确性、机制推理、优先级判断、数据解释、安全意识、患者友好表达、识别信息边界。
