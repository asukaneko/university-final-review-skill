# 人文学科

适用于历史、哲学、文学、语言、古典学、宗教学、文化研究、语言学、艺术史等人文学科课程。

## 子学科速查

| 子学科 | 典型课程 | 重点题型 |
| --- | --- | --- |
| 历史学 | 中国史、世界史、史学理论、专门史 | 时间线分析、原因-结果、史学争论 |
| 哲学 | 中国哲学、西方哲学、伦理学、美学、逻辑学 | 论证重构、概念分析、比较评价 |
| 文学 | 中国文学、外国文学、比较文学、文学理论 | 文本细读、主题分析、比较研究 |
| 语言学 | 语言学概论、现代汉语、古代汉语、应用语言学 | 结构分析、语料解释、理论应用 |
| 宗教学 | 宗教学概论、佛教、道教、基督教、伊斯兰教 | 概念解释、比较研究、文化分析 |
| 艺术史 | 中国美术史、西方美术史、设计史 | 作品分析、风格比较、历史语境 |

## 复习目标

帮助学生形成解释深度：关键文本、概念、背景、论证、证据、史学争论、细读能力、比较分析和可用于作文的论点结构。

## 需要从材料中提取什么

- 原典、段落、艺术作品、历史事件、思想家、理论、流派和争论。
- 关键词、概念、母题、主题、时间线、体裁规则和文化背景。
- 老师的解释、课堂论点、研讨争论和作文题。
- 证据类型：引文、事件、图像、档案事实、语言例子或哲学命题。
- 作文、文本评注、翻译或简答题评分标准。

## 每章笔记结构

1. **中心问题**：本章处理什么解释或历史问题。
2. **背景**：时代、作者、运动、流派、社会/政治语境。
3. **关键概念和术语**：定义、细微差别、例子。
4. **论证图**：主张、分论点、证据、影响。
5. **证据库**：引文/事件/段落/图像及其分析用途。
6. **争论或史学观点**：不同解释。
7. **比较表**：思想家、文本、时期、流派或主题。
8. **作文论点模板**。
9. **常见错误**：复述情节、无证据断言、时代错置、比较空泛。
10. **练习题**和提纲。

## 常见题型

- 定义并解释概念、运动、时期或方法。
- 细读或段落评注。
- 比较文本、作者、思想家、事件或解释。
- 主题作文或论证作文。
- 时间线、原因-结果、延续-变化题。
- 语言类课程中的翻译、语法或文本分析。

## 解题模板

### 文本细读

使用：**观察 → 证据 → 技法/形式 → 意义 → 背景 → 对论点的重要性**。

1. 观察：这段文本/这幅图像有什么特征。
2. 证据：哪些具体细节支持你的观察。
3. 技法/形式：作者/艺术家使用了什么手法。
4. 意义：这些手法产生了什么效果。
5. 背景：在什么历史/文化/作者背景下理解。
6. 对论点的重要性：如何服务于整体论证。

### 历史题

使用：**主张 → 时间线/背景 → 原因 → 证据 → 后果 → 史学争论 → 判断**。

1. 主张：你的核心论点是什么。
2. 时间线/背景：事件发生的时间和环境。
3. 原因：直接原因和深层原因。
4. 证据：用什么史料支持。
5. 后果：短期和长期影响。
6. 史学争论：不同历史学家的解释。
7. 判断：你支持哪种解释，为什么。

### 哲学题

使用：**论点 → 论证重构 → 假设 → 反驳 → 回应 → 评价**。

1. 论点：哲学家的核心主张。
2. 论证重构：用清晰的逻辑重述论证。
3. 假设：论证依赖什么前提。
4. 反驳：有什么反对意见。
5. 回应：哲学家如何回应反驳。
6. 评价：你认为论证是否成立。

### 比较题

使用：**比较维度 → 各对象分析 → 共同点 → 差异点 → 解释差异原因 → 评价**。

1. 确定比较维度（主题、方法、影响、时代背景等）。
2. 对每个对象在各维度上进行分析。
3. 指出共同点和差异点。
4. 解释差异的原因。
5. 给出评价性结论。

### 论证作文

1. 确定中心论点（可争议的、有证据支持的）。
2. 列出分论点（每个都有证据）。
3. 组织论证结构（递进、并列或对比）。
4. 处理反方观点。
5. 得出有深度的结论。

## 题库生成规则

建议比例：

- 20% 关键词和背景检查。
- 25% 基于证据的简答。
- 25% 比较和解释题。
- 20% 作文题和提纲。
- 10% 段落/图像/史料评注。

答案要示范如何从证据走向解释，而不只是列事实。

## 高频考点预测信号

优先关注：

- 贯穿多次课或阅读的核心主题。
- 与命名理论、争论或转折点相关的内容。
- 有充足证据库的内容：引文、日期、图像、段落。
- 适合"比较、评价、讨论、分析、解释"等题干动词的内容。

## 主动复习方法

- 主动回忆：凭记忆写中心论点。
- 做证据卡：引文/事件 + 可支持的分析。
- 限时写一段论证段。
- 做时间线、概念图和比较表。
- 口头讲一个争论：一种解释、反解释、自己的判断。
- 仿写范答的论证结构。

## 常见易错点清单

| 易错类型 | 例子 | 预防方法 |
| --- | --- | --- |
| 复述情节 | 只讲故事不分析 | 每段都有分析句 |
| 无证据断言 | "这首诗很美" | 引用具体诗句 |
| 时代错置 | 用现代观念解释古人 | 注意历史语境 |
| 比较空泛 | "两者都很重要" | 找具体共同点和差异 |
| 论点模糊 | "这个问题很复杂" | 写出可争议的具体论点 |
| 忽略争论 | 只呈现一种解释 | 至少提两种观点 |

## 评分 Rubric

给分点包括：论点清晰、背景准确、证据选择、分析深度、回应争论、结构和语言精确性。
