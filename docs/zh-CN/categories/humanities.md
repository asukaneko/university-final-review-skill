# 文史哲 / 语言文学

适用于历史、哲学、文学、语言学、文化研究、宗教学等人文学科课程。

## 复习重点

- 核心概念、人物、流派、文本、事件和时代背景
- 时间线、思想发展、观点论证和解释路径
- 文本细读、材料证据和论点构建
- 不同思想、作者、时期、运动或作品之间的比较
- 论述题和材料分析题的答题结构

## 每章推荐结构

1. 时间线或概念图
2. 关键词、人物、文本和流派
3. 核心观点和历史背景
4. 重要材料、事件或例子
5. 对比表
6. 论述题答题模板
7. 常见误读和过度简化
8. 练习论述题和提纲

## 常见题型

- 名词解释
- 简答题
- 时间线或发展脉络题
- 文本解读题
- 比较题
- 论述题

## 输出重点

帮助学生从“背事实”过渡到“组织论证”。论述题应提供中心论点、证据、分析层次和结论句。
