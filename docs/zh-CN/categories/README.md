# 学科大类复习指南

这些文档用于把大学期末复习 Skill 适配到不同专业和课程类型，而不是只服务计算机课程。

## 如何选择大类

课程属于单一专业时，直接使用对应大类。课程交叉时，可以组合多个大类。例如：医学伦理可以结合“医学/健康”和“法学/人文”；教育心理学可以结合“教育”和“社会科学”。

## 通用复习包

无论哪个学科，完整复习资料都应保留以下结构：

1. 课程总体框架
2. 逐章复习讲义
3. 考点预测
4. 章节题库
5. 背诵提纲
6. 学科专属解题/分析模板
7. 考前冲刺清单
8. 模拟卷和评分要点
