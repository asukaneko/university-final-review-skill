# 学科大类复习指南

这些文档用于把大学期末复习 Skill 适配到不同专业和课程类型，而不是只服务计算机课程。

## 如何选择大类

课程属于单一专业时，直接使用对应大类。课程交叉时，可以组合多个大类。例如：

- 医学伦理：结合"医学/健康"和"法学/人文"
- 教育心理学：结合"教育"和"社会科学"
- 商法：结合"商科/经济"和"法学"
- 技术写作：结合"计算机/工程"和"人文学科"
- 健康经济学：结合"医学/健康"和"经管/经济"

## 子学科速查

每个大类都包含子学科速查表，列出典型课程和重点题型，帮助快速定位最相关的复习模式。

## 通用复习包

无论哪个学科，完整复习资料都应保留以下结构：

1. 课程总体框架和考试范围
2. 学科大类和复习策略（含子学科分解）
3. 基于学习科学的复习计划（含间隔复习时间表）
4. 逐章复习讲义（含学科专属结构）
5. 考点预测（含优先级排序：必考点/高频考点/低频易拿分）
6. 概念对比表、公式/规则表
7. 章节题库（含四档难度：基础/常考/综合/迁移）
8. 测试卡片（可导出 CSV 和交互式 HTML）
9. 背诵提纲（含多种记忆法：关键词串联、口诀、首字母、画面联想）
10. 学科专属解题/分析模板
11. 易错点分析和预防策略
12. 错题日志和薄弱点修复计划
13. 考前冲刺清单（含时间分配建议）
14. 精准模拟卷（含评分 Rubric 和考后诊断）

## 跨学科组合

当课程涉及多个学科领域时：

1. 确定主要学科和次要学科。
2. 用主要学科的模板为主。
3. 补充次要学科的专属内容。
4. 在交叉部分用组合模板。

## 质量检查

完成复习包后检查：

- [ ] 章节结构是否完整覆盖考试范围
- [ ] 概念定义是否准确、清晰
- [ ] 公式和定理是否包含适用条件
- [ ] 题库是否覆盖多种难度和题型
- [ ] 答案解析是否足够详细
- [ ] 易错点是否明确标注
- [ ] 背诵提纲是否可直接使用
- [ ] 模拟卷是否符合考试格式
- [ ] 所有内容是否基于上传资料
- [ ] 补充内容是否标注为"补充背景"
