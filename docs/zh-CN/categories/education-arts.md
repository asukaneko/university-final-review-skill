# 教育 / 艺术 / 设计

适用于教育学、课程论、教学法、艺术史、音乐、设计、媒体创作、视觉传达和创意实践类课程。

## 复习重点

- 教育理论、学习目标、教学方法、评价方式和课堂案例
- 艺术流派、作品、作者、风格、媒介、技法和历史背景
- 设计原则、批评框架、用户需求、视觉语言和作品集表达
- 教案分析、作品赏析、反思写作和创作过程说明

## 每章推荐结构

1. 核心概念、理论、作品或方法
2. 历史、教育或设计背景
3. 分析或批评框架
4. 案例、作品、教案或项目解读
5. 理论、风格或方法对比
6. 练习题和答题提纲
7. 基于评分标准的答题模板
8. 考前复习清单

## 常见题型

- 概念解释
- 理论或风格比较
- 案例 / 教案分析
- 作品或设计批评
- 反思写作
- 作品集或创作过程说明
- 论述题

## 输出重点

教育类课程要连接理论、学习者需求、教学方法和评价方式。艺术与设计类课程要连接背景、形式、技法、意义和批评。
