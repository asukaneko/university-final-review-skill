# 法学 / 法律研究

适用于法学、法律研究、公共政策法、商法、刑法、宪法、侵权法、合同法、行政法、国际法和法理学等课程。

## 复习目标

把法律材料整理成考试可用的规则、要件、权威依据、政策理由、争点识别线索和事实适用框架。

## 需要从材料中提取什么

- 法律原则、条文、案例规则、测试标准、构成要件、例外和证明责任。
- 老师使用的事实模式、假设案例、习题和往年题争点。
- 不同解释、政策理由、反对意见和改革讨论。
- 特定法域要求和引用规范。
- 评分 Rubric、范文和反馈意见。

## 每章笔记结构

1. **主题图**：法律领域、子争点、规则之间的关系。
2. **规则陈述**：简明规则、来源、要件、例外。
3. **案例表**：案名、关键事实、争点、裁判要旨、推理、考试用途。
4. **条文解释**：关键词、门槛、抗辩、救济。
5. **争点触发词**：哪些事实会激活该规则。
6. **适用模式**：如何正反两面论证。
7. **政策/理由**：规则为什么存在，有何批评。
8. **常见错误**：先下结论、漏要件、无依据断言。
9. **练习假设案例**和 IRAC 范答。

## 常见题型

- 案例分析 / 争点识别题。
- 案例和规则解释。
- 条文解释。
- 关于原则、政策、改革或理论的论述题。
- 比较法域、案例、原则或测试标准。
- 救济、责任、抗辩或程序问题。

## IRAC / CRAC 模板

使用 **Issue → Rule → Application → Conclusion** 或 **Conclusion → Rule → Application → Conclusion**。

每个争点：

1. 把法律争点写成问题。
2. 陈述规则、要件和权威来源。
3. 把每个要件应用到具体事实。
4. 处理反方观点和不确定事实。
5. 得出有限度的结论。
6. 相关时说明救济、抗辩或后果。

## 论述题模板

使用：**中心论点 → 法律框架 → 权威依据 → 分析 → 反驳 → 评价 → 结论**。

好的法律论述题不是罗列规则，而是评价规则的政策、协调性、公平、效率、权利保护、机构能力和改革意义。

## 题库生成规则

建议比例：

- 20% 规则/要件/案例意义记忆。
- 40% 争点识别型案例题。
- 20% 短案例/条文适用题。
- 20% 论述或政策评价题。

范答要展示事实到法律的推理，并在事实模糊处给出替代论证。

## 高频考点预测信号

优先关注：

- 有多要件测试和例外的规则。
- 有重要案例或条文的内容。
- 在假设案例或习题中反复出现的内容。
- 能正反两面论证的内容。
- 能连接政策讨论或救济的内容。

## 主动复习方法

- 记规则骨架，而不是整段背诵。
- 每天用短事实练争点识别。
- 做案例卡：事实、争点、规则、推理、考试用途。
- 限时写 IRAC 并对照 Rubric。
- 用对比表区分相似原则和抗辩。

## 评分 Rubric

给分点包括：争点识别、规则和权威准确性、逐要件适用、事实使用、反方观点、结构化结论、相关政策洞见。
