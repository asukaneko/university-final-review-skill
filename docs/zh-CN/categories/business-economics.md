# 商科 / 经济学

适用于经济学、金融、会计、市场营销、管理、运营、创业、商业分析、战略和组织行为课程。

## 子学科速查

| 子学科 | 典型课程 | 重点题型 |
| --- | --- | --- |
| 经济学 | 微观经济学、宏观经济学、计量经济学 | 图形分析、模型应用、政策评价 |
| 金融学 | 公司金融、投资学、金融市场、风险管理 | 估值计算、投资决策、风险分析 |
| 会计学 | 财务会计、管理会计、审计、税法 | 分录编制、报表分析、成本计算 |
| 市场营销 | 市场营销原理、消费者行为、品牌管理、数字营销 | 案例分析、STP 分析、营销方案 |
| 管理学 | 管理学原理、战略管理、人力资源管理、组织行为学 | 案例分析、框架应用、组织诊断 |
| 运营管理 | 运营管理、供应链管理、质量管理、项目管理 | 流程优化、库存模型、项目计划 |

## 复习目标

把商科和经济学材料整理成模型选择、计算、案例诊断、基于证据的建议和约束下管理判断的框架。

## 需要从材料中提取什么

- 模型、框架、定义、假设、图形、公式和决策规则。
- 财务报表、比率、会计规则、估值方法、成本行为和预算逻辑。
- 经济图形、均衡分析、弹性、优化、福利和政策影响。
- 营销/战略/管理案例、框架、利益相关者图和执行风险。
- 定量方法、数据表、仪表盘、回归输出和解释规则。
- 往年案例题、计算格式和评分 Rubric。

## 每章笔记结构

1. **决策问题**：本章支持什么商业/经济决策。
2. **核心框架/模型**：假设、变量、图形、何时使用。
3. **公式和计算表**：符号、步骤、解释。
4. **案例应用指南**：提取哪些事实、如何诊断、如何给建议。
5. **图表解释**：坐标轴、移动、趋势、管理含义。
6. **比较表**：模型、战略、财务比率、市场结构。
7. **例题**：数字题、图形题、案例题。
8. **风险和局限**。
9. **常见错误**：混淆利润/现金、相关/因果、平均/边际、战略/战术。
10. **练习题**。

## 常见题型

- 定义概念并比较框架。
- 计算比率、成本、NPV、弹性、均衡、预测或会计分录。
- 解读图、表、财务报表、回归结果或仪表盘。
- 分析商业案例并提出建议。
- 评价战略、市场行为、政策影响或组织问题。
- 写简短备忘录或执行建议。

## 解题模板

### 定量商科/经济题

1. 判断决策问题或模型。
2. 列出数据、假设、时间范围和单位/货币。
3. 分步骤应用公式。
4. 解释结果：对决策意味着什么。
5. 做敏感性或局限说明。
6. 如题目要求，给出建议。

### 案例分析

使用：**情境 → 问题 → 证据 → 框架 → 选项 → 评价标准 → 建议 → 执行风险**。

### 经济图形题

使用：**初始均衡 → 冲击/变化 → 曲线移动 → 新均衡 → 福利/分配影响 → 政策含义**。

### 会计分录题

1. 分析交易性质。
2. 确定受影响的账户。
3. 判断借贷方向。
4. 检查借贷平衡。
5. 编制分录并附说明。

### 财务报表分析

1. 计算关键比率（流动性、盈利性、杠杆、效率）。
2. 与行业基准和历史数据比较。
3. 解释比率的管理含义。
4. 识别趋势和异常。
5. 给出改善建议。

### 战略分析

1. 外部环境分析（PESTEL、五力模型）。
2. 内部资源分析（价值链、VRIO）。
3. 战略定位（SWOT、战略群组）。
4. 战略选择和评价。
5. 实施建议和风险。

## 框架速查表

| 框架 | 用途 | 关键要素 |
| --- | --- | --- |
| SWOT | 战略定位 | 优势、劣势、机会、威胁 |
| 波特五力 | 行业分析 | 供应商、买方、替代品、新进入者、竞争 |
| PESTEL | 宏观环境 | 政治、经济、社会、技术、环境、法律 |
| STP | 市场战略 | 细分、目标、定位 |
| 4P/7P | 营销组合 | 产品、价格、渠道、促销 |
| NPV | 投资决策 | 现金流、折现率、净现值 |
| 盈亏平衡 | 成本分析 | 固定成本、变动成本、销售价格 |
| BCG 矩阵 | 业务组合 | 明星、现金牛、问题、瘦狗 |

## 题库生成规则

建议比例：

- 20% 概念/框架记忆。
- 25% 计算和图表解释。
- 30% 案例诊断和建议。
- 15% 论述/政策/战略评价。
- 10% 综合混合题。

答案要包含解释和管理/经济含义，而不只是数字。

## 高频考点预测信号

优先关注：

- 能把公式/图形与实际决策结合的内容。
- 在作业、案例讨论和习题中反复出现的内容。
- 标准框架：SWOT、波特五力、STP、4P、NPV、盈亏平衡、供需模型等。
- 有常规计算格式或决策取舍的内容。

## 主动复习方法

- 建立模型选择表：每个框架/公式何时使用。
- 反复练计算，直到建模步骤自动化。
- 限时写一页案例建议。
- 主动回忆图形和公式解释。
- 比较相似指标和框架，避免替换错误。
- 框架练习：给一个案例，尝试用 2-3 个不同框架分析。

## 常见易错点清单

| 易错类型 | 例子 | 预防方法 |
| --- | --- | --- |
| 利润≠现金流 | 赚钱但没现金 | 区分利润表和现金流量表 |
| 图形方向错 | 供给需求移动反了 | 先确定冲击来源 |
| 比率颠倒 | 流动资产/流动负债写反 | 记住分子分母含义 |
| NPV 时点错 | 期初vs期末现金流 | 画时间轴 |
| 案例空泛 | 建议没有可操作性 | 具体到行动步骤 |
| 混淆平均和边际 | 平均成本=边际成本 | 画 U 形曲线 |

## 评分 Rubric

给分点包括：模型/框架选择、计算正确性、结果解释、证据使用、建议质量、风险意识和简洁商业表达。
