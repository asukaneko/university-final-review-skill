# 理学 / 数学 / 自然科学

适用于数学、物理、化学、生物、环境科学、统计学以及实验类自然科学课程。

## 复习重点

- 核心概念、定律、定理、定义和适用条件
- 公式推导、单位、假设和边界条件
- 实验方法、变量、对照、误差和结果解释
- 图像、模型、反应过程、数据表和机制图
- 证明、计算和科学推理链条

## 每章推荐结构

1. 概念图和关键词
2. 定律、定理、公式或生物机制
3. 假设条件和适用范围
4. 推导过程或机制过程
5. 实验 / 数据分析模板
6. 计算题、证明题或机制题示例
7. 常见误区
8. 练习题和答案解析

## 常见题型

- 概念识别和定义题
- 公式选择和计算题
- 推导题或证明题
- 图示标注题
- 实验设计和误差分析
- 数据解释题
- 机制说明题

## 输出重点

必须讲清楚单位、假设、适用条件，以及从已知条件推到结论的过程。
