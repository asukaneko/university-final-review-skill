# 自然科学 / 数学

适用于数学、统计、物理、化学、生物、环境科学、天文、地质等理论或实验科学课程。

## 复习目标

建立对原理、模型、证据、公式、证明、机制和实验推理的连接性理解，使学生能解决陌生问题、解释现象并解读数据。

## 需要从材料中提取什么

- 定律、定理、原理、模型、定义和分类体系。
- 公式推导、假设、适用范围、单位和极限情况。
- 证明结构、引理、常见变换和标准技巧。
- 生物/化学/物理机制、通路、反应、循环和因果链。
- 实验设计、变量、对照、仪器、图表、统计检验和误差来源。
- 例题、习题课、实验报告和往年题风格。

## 每章笔记结构

1. **核心问题**：本章回答什么科学或数学问题。
2. **概念图**：原理、模型、变量和依赖关系。
3. **定义与假设**：精确定义和适用范围。
4. **公式/定理表**：陈述、符号、单位、假设、何时不能用。
5. **机制/证明路径**：因果或逻辑链条。
6. **图表/数据解释**：坐标轴、趋势、异常、误差、结论。
7. **例题**：基础题、考试题、概念陷阱题。
8. **实验连接**：对照、变量、方法、结果、局限。
9. **常见误区**：直觉错误、符号/单位错误、相关不等于因果。
10. **练习题**：概念、定量、证明/机制、数据解释。

## 常见题型

- 定义、比较、分类或解释原理/机制。
- 推导、公式变形和证明。
- 带单位和假设的定量计算。
- 解读图、表、谱图、显微图、实验数据。
- 解释实验设计、对照、效度、信度和误差。
- 把定理/模型/机制应用到新情境。

## 解题模板

### 定量科学题

1. 判断现象、系统和模型。
2. 列出已知、未知、单位、假设和常数。
3. 选择方程并说明适用性。
4. 能先符号求解就先符号求解。
5. 跟踪单位和有效数字。
6. 从物理/生物/化学意义解释结果。

### 证明 / 定理题

1. 明确要证明什么。
2. 列出定义、假设和可用定理。
3. 选择策略：直接证明、反证、归纳、构造、反例。
4. 每一步写理由，而不只是代数变形。
5. 检查边界情况和结论。

### 实验 / 数据题

使用：**问题 → 假设 → 变量/对照 → 方法 → 数据模式 → 结论 → 局限**。

## 题库生成规则

建议比例：

- 20% 定义和概念比较。
- 25% 计算或公式变形。
- 20% 证明、推导或机制解释。
- 20% 图表/数据/实验解释。
- 15% 综合应用题。

答案必须解释假设、单位、推理，以及为什么常见错误答案不对。

## 高频考点预测信号

优先关注：

- 能连接多个章节或解释多个现象的内容。
- 具有明确解题步骤的公式/定理。
- 在实验、习题和作业中出现的内容。
- 通过图、机制、推导或数据呈现的内容。
- 容易产生误解的内容。

## 主动复习方法

- 把公式/定理做成卡片：条件、例子和反例都要有。
- 默画通路、循环、图像、证明和模型。
- 先学例题，再做近迁移和远迁移题。
- 混合题型，避免只靠识别套路。
- 做“模型选择表”：每个方程/定理何时适用。

## 评分 Rubric

给分点包括：模型选择、定义准确性、假设说明、数学/科学推理、中间步骤、单位和有效数字、数据解释、结论质量。
