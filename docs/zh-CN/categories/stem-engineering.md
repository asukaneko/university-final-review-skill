# 计算机 / 工程技术

适用于计算机科学、软件工程、信息系统、数据科学、电子信息、机械、土木、自动化、机器人等工程技术类课程。

## 子学科速查

| 子学科 | 典型课程 | 重点题型 |
| --- | --- | --- |
| 计算机科学 | 数据结构、算法、操作系统、编译原理、计算机网络 | 算法追踪、系统设计、协议分析 |
| 软件工程 | 软件工程、需求工程、测试、项目管理 | 设计模式、UML、测试用例、案例分析 |
| 数据科学 | 数据库、数据挖掘、机器学习、统计学习 | SQL、模型选择、调参、结果解释 |
| 电子信息 | 信号与系统、数字电路、通信原理、电磁场 | 波形分析、频谱、电路计算、调制解调 |
| 机械工程 | 材料力学、机械设计、热力学、控制工程 | 受力分析、强度校核、热力循环、PID |
| 土木工程 | 结构力学、土力学、混凝土设计、钢结构 | 内力图、地基承载力、配筋计算 |
| 自动化 | 控制理论、PLC、嵌入式、机器人学 | 传递函数、状态空间、控制系统设计 |

## 复习目标

把技术资料整理成可考试使用的工具包：概念、机制、公式、算法、工程权衡、实验依据和可重复执行的解题流程。

## 需要从材料中提取什么

- 定义、模型、体系结构、系统组成。
- 算法、流程、控制逻辑、协议、设计模式。
- 公式、推导、适用前提、单位、边界条件和约束。
- 复杂度、性能、可靠性、正确性、安全性、成本和可扩展性权衡。
- 实验流程、实现细节、测量结果、误差来源和故障排查。
- 作业模式、往年题模式、老师反复强调的例子。

## 每章笔记结构

1. **问题背景**：本章解决什么实际问题。
2. **知识结构图**：对象、关系、输入、输出、约束。
3. **核心定义**：精确定义和对比概念，如进程/线程、栈/堆、应力/应变。
4. **机制或算法**：分步骤说明，必要时给伪代码和图示。
5. **公式与推导表**：公式、符号、单位、假设、常见变形。
6. **例题**：基础题、考试难度题、边界/陷阱题。
7. **实现或实验要点**：代码、电路、装置、数据处理或调试清单。
8. **取舍表**：何时选择方法 A，何时选择方法 B。
9. **易错点**：越界、单位、错误假设、隐藏约束。
10. **练习题**：快速检查、中等题、综合设计/调试题。

## 常见题型

- 定义比较和简答解释。
- 算法追踪、时间/空间复杂度、正确性说明。
- 代码、伪代码、SQL、电路分析、工艺/配置任务。
- 公式代入、推导、量纲分析和工程计算。
- 系统设计、架构选择、故障诊断、性能优化。
- 实验解释：结果说明、误差来源、实验改进。

## 解题模板

### 算法 / 代码题

1. 重述输入、输出、约束和边界情况。
2. 选择数据结构或工程模型，并说明理由。
3. 给出算法或流程步骤。
4. 说明正确性：不变量、终止性或工程依据。
5. 分析复杂度、资源消耗和局限。
6. 用普通样例、边界样例、失败样例测试。

### 工程计算题

1. 画出或描述系统边界。
2. 列出已知量、未知量、单位、假设和相关定律。
3. 选择公式并说明适用原因。
4. 带单位代入计算。
5. 检查合理性：符号、数量级、守恒关系、物理意义。
6. 给出带单位的最终答案和解释。

### 设计 / 取舍题

使用：**需求 → 候选方案 → 评价标准 → 决策 → 风险 → 缓解措施**。

### 系统分析题

1. 识别系统组件和它们的职责。
2. 画出组件之间的交互图。
3. 分析数据流和控制流。
4. 识别瓶颈和潜在问题。
5. 提出优化建议。

### 实验 / 调试题

1. 描述实验目的和方法。
2. 分析实验数据和结果。
3. 识别误差来源。
4. 提出改进建议。
5. 连接理论和实践。

## 题库生成规则

建议比例：

- 25% 概念检查和定义辨析。
- 25% 流程、算法或机制追踪。
- 25% 计算、代码、推导或实验数据解释。
- 15% 设计、取舍、调试题。
- 10% 综合型往年题风格题。

答案不仅给最终结果，还要写出推理路径、假设和常见错误选项。

## 高频考点预测信号

优先关注：

- 在 PPT、实验、作业、习题和往年题中反复出现的内容。
- 是后续章节解题基础的内容。
- 伴随公式、算法、图、命名方法的内容。
- 适合限时考试测试的内容。
- 老师用例子、提醒或"比较/区别"强调的内容。

## 主动复习方法

- 主动回忆：合上笔记默写算法、公式、图和设计取舍。
- 先看完整例题，再逐步遮住步骤，直到能独立完成。
- 混合练习相似题型，如调度算法、电路定理、受力情况。
- 做一页"考试操作表"：流程、公式、边界情况、调试检查。
- 代码题：先手写伪代码，再上机验证。
- 设计题：用白板画架构图，边画边讲解理由。

## 常见易错点清单

| 易错类型 | 例子 | 预防方法 |
| --- | --- | --- |
| 边界条件 | 数组越界、空指针 | 列出所有边界情况 |
| 单位遗漏 | 混淆 ms 和 s | 全程带单位计算 |
| 复杂度分析 | 遗漏额外空间 | 逐步分析每层循环 |
| 假设遗漏 | 算法假设输入有序 | 先检查前提条件 |
| 图示错误 | 内力图画反 | 用截面法验证 |
| 协议细节 | TCP 握手步骤顺序 | 画时序图 |

## 评分 Rubric

给分点包括：模型/公式/算法选择、过程清晰度、中间步骤、计算或实现细节、假设和约束处理、解释与取舍意识、最终答案表达。
