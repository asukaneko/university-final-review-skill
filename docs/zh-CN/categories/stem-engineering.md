# 计算机 / 工程技术

适用于计算机科学、软件工程、信息系统、电子信息、机械、土木、自动化等工程技术类课程。

## 复习重点

- 定义、模型、体系结构和系统组成
- 算法、流程、公式和工程约束
- 复杂度、性能、正确性、可靠性和权衡关系
- 实验流程、实现细节和结果分析
- 常见计算题、代码题、设计题和故障分析题

## 每章推荐结构

1. 知识结构图
2. 核心定义
3. 机制或算法解释
4. 公式、推导或规则总结
5. 手算例题或代码例题
6. 伪代码或 C++ 实现
7. 常见设计题 / 调试题
8. 易错细节
9. 章节练习题

## 常见题型

- 选择题、填空题中的定义辨析
- 简答题中的机制解释
- 计算题或推导题
- 算法执行过程追踪和复杂度分析
- 代码阅读或代码实现
- 系统设计或工程取舍分析

## 输出重点

每个技术点都要讲清楚：它解决什么问题、如何工作、什么时候适用、考试题怎么做。
