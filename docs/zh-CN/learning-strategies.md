# 基于学习科学的复习策略

在生成任何期末复习包时，都应把本指南作为跨学科通用层。目标是避免被动摘要，把资料转化为主动回忆、练习、迁移和考试表现工具。

## 核心原则

### 1. 主动回忆

不要只让学生重读笔记。每章都要转化为需要主动提取的任务：

- 空白页默写；
- 合上资料画概念图；
- 带例子和反例的闪卡；
- 用费曼技巧口头解释；
- 先做简答题，再看答案。

### 2. 间隔复习

不要把复习全部堆到考前：

- 当天：重建章节框架；
- 第二天：不看笔记回答关键问题；
- 3-4 天后：做混合练习；
- 1 周后：完成限时小测；
- 最后冲刺：聚焦弱点和高频模板。

### 3. 测试式学习

练习要尽量接近考试：

- 限时；
- 混合章节；
- 第一遍不看资料；
- 配答案和评分 Rubric；
- 批改后写错题日志。

### 4. 例题递减支持

对题目型课程，先看完整例题，再逐步减少提示：

1. 学完整解答；
2. 解释每一步为什么这样做；
3. 带提示做相似题；
4. 无提示完成；
5. 做表面特征变化的迁移题。

### 5. 交错练习和迁移

把相似主题混在一起，让学生练习"选择方法"，而不是机械套套路。例如：

- 条件不同但形式相近的公式；
- 构成要件不同但容易混淆的法律原则；
- 红旗征不同的相似疾病；
- 机制不同的相似理论；
- 决策目的不同的商业框架。

### 6. 精细加工

鼓励学生把新知识和已有知识建立连接：

- 用自己的话重写定义；
- 给抽象概念举具体例子；
- 画出概念之间的因果关系；
- 用类比解释复杂机制；
- 把公式和现实场景绑定。

### 7. 元认知监控

帮助学生评估自己的掌握程度：

- 每次练习后标注"完全掌握 / 需要复习 / 不会"；
- 用"能不看笔记解释给别人听"作为掌握标准；
- 定期回顾错题日志，识别反复出错的模式；
- 在模拟考试后做考后诊断分析。

## 学科专属复习策略

### STEM / 工程技术

**核心方法**：例题递减 + 交错练习

- 先精做 3-5 道经典例题，再逐步增加难度和变化；
- 把算法、公式、设计模式做成操作卡，标注适用条件；
- 混合练习：同一道题可能同时考复杂度分析和正确性证明；
- 做一页"考试操作表"：列出常用公式、边界情况、调试检查点；
- 对代码/算法题：先手写伪代码，再上机验证，再优化。

**特别适用**：
- 费曼技巧（给非技术人员解释系统设计）
- 空白页默写（默写数据结构、算法步骤、系统架构）
- 对比表（不同算法的时间/空间复杂度对比）

### 自然科学 / 数学

**核心方法**：证明递减 + 模型选择训练

- 把公式/定理做成条件卡：什么条件下能用、什么条件下不能用；
- 每个定理至少准备一个标准证明和一个反例；
- 默画通路、循环、图像、证明和模型；
- 做"模型选择表"：每个方程/定理何时适用；
- 混合题型，避免只靠识别套路。

**特别适用**：
- 概念图（画出定理之间的逻辑关系）
- 迁移练习（把同一公式应用到不同物理场景）
- 图像解释（同一张图从不同角度提问）

### 医学 / 健康

**核心方法**：疾病脚本 + 临床推理训练

- 用空白页默写疾病脚本：定义 → 机制 → 表现 → 检查 → 处理 → 安全；
- 用表格比较相似疾病，重点标注鉴别点；
- 限时练病例并口头说出推理链；
- 用间隔复习记解剖、药物类别、实验室值和诊断标准；
- 做"红旗征速查卡"：列出必须立即识别的危险信号。

**特别适用**：
- 疾病脚本卡片（正面给症状，反面给完整推理链）
- 药物安全卡（机制 → 用途 → 不良反应 → 禁忌 → 监测）
- OSCE 演练（口头模拟临床沟通和操作步骤）

### 法学

**核心方法**：争点识别训练 + IRAC 递减

- 记规则骨架（要件 + 例外），而不是整段背诵；
- 每天用短事实练争点识别（2-3 分钟快速判断）；
- 做案例卡：事实 → 争点 → 规则 → 推理 → 考试用途；
- 限时写 IRAC 并对照 Rubric；
- 用对比表区分相似原则和抗辩。

**特别适用**：
- 争点触发词卡片（看到什么事实就想到什么规则）
- 反方观点练习（同一案例写正反两面论证）
- 条文解释训练（同一法条的不同解释可能性）

### 人文学科

**核心方法**：证据卡 + 论证结构训练

- 做证据卡：引文/事件/图像 + 可支持的分析角度；
- 限时写一段论证段（10 分钟内完成一个完整论证）；
- 做时间线、概念图和比较表；
- 口头讲一个争论：一种解释 → 反解释 → 自己的判断；
- 主动回忆：凭记忆写中心论点和关键论据。

**特别适用**：
- 论点卡片（正面给主题，反面给论点 + 证据 + 分析）
- 比较表（同一主题的不同解释并列）
- 段落仿写（模仿范答的论证结构）

### 社会科学

**核心方法**：理论卡 + 方法批判训练

- 做理论卡：假设 → 机制 → 证据 → 批评 → 例子；
- 用同一个案例练习套用多种理论；
- 重画研究设计并识别效度威胁；
- 用间隔复习记理论家、构念和研究发现；
- 针对高频作文动词写限时段落提纲。

**特别适用**：
- 理论对比卡（正面给现象，反面给 2-3 种理论解释）
- 方法批判练习（给一个研究设计，找出效度威胁）
- 政策分析模板（问题 → 证据 → 选项 → 建议）

### 商科 / 经济

**核心方法**：模型选择表 + 案例诊断训练

- 建立模型选择表：每个框架/公式何时使用；
- 反复练计算，直到建模步骤自动化；
- 限时写一页案例建议（20 分钟内完成）；
- 主动回忆图形和公式解释；
- 比较相似指标和框架，避免替换错误。

**特别适用**：
- 框架选择卡（正面给商业问题，反面给适用框架 + 理由）
- 图形移动训练（给初始均衡，让学生画出冲击后的新均衡）
- 财务比率速查卡（公式 + 含义 + 行业基准）

### 教育 / 艺术 / 设计

**核心方法**：原则-例子配对 + 批评写作训练

- 做理论/原则卡片，并配具体教学/设计案例；
- 用同一模板分析陌生案例；
- 建立作品集证据图：标准 → 作品 → 说明；
- 口头练习教案/设计理由（为什么选择这个策略/形式）；
- 间隔反思：回看反馈并写下一步行动。

**特别适用**：
- 教案分析卡（正面给教学情境，反面给分析框架 + 答案）
- 批评词汇卡（积累精确的分析和评价词汇）
- 反思写作模板（经历 → 证据 → 解释 → 理论连接 → 改进）

## 输出要求

完整复习包应包含：

- 每章主动回忆问题；
- 最后一周间隔复习计划；
- 混合练习或模拟测试；
- 错题日志模板；
- 例题或范答；
- 要求把知识应用到陌生情境的迁移题；
- 学科专属复习策略建议；
- 考前时间分配建议。

## 错题日志模板

| 题目 | 错误类型 | 错因 | 正确规则/流程 | 预防提示 |
| --- | --- | --- | --- | --- |
| Q1 | 概念 / 计算 / 应用 / 审题 | 漏看条件 | 该定理只在……时使用 | 先检查假设 |

## 考前一周节奏

- **第 7-5 天**：凭记忆重建笔记并修补漏洞。
- **第 4-3 天**：混合练习和例题递减支持。
- **第 2 天**：限时模拟卷和错题日志复盘。
- **第 1 天**：公式/规则/证据表，轻量回忆，不大量学习新内容。

## 考前时间分配建议

| 距考试时间 | 策略 | 重点 |
| --- | --- | --- |
| 2 周以上 | 系统复习 + 间隔练习 | 完整讲义 + 章节题库 |
| 1 周 | 混合练习 + 薄弱点修复 | 错题日志 + 模拟卷 |
| 3 天 | 高频考点 + 记忆卡 | 背诵提纲 + 速记版 |
| 1 天 | 轻量回忆 + 心理准备 | 公式表 + 信心建立 |
| 考前 1 小时 | 快速浏览 | 速记版 + 易错点 |

## 常见复习误区

| 误区 | 问题 | 改进 |
| --- | --- | --- |
| 反复阅读笔记 | 被动输入，缺乏提取练习 | 每读一节就合上笔记默写 |
| 只做简单题 | 无法应对考试难度 | 从基础题开始，逐步过渡到综合题 |
| 逐章复习不混合 | 考试是混合的，复习也应混合 | 后期加入跨章节混合练习 |
| 考前通宵 | 睡眠不足影响记忆巩固 | 保证睡眠，考前只做轻量回忆 |
| 只背不理解 | 无法应对变化题型 | 先理解机制，再记忆关键点 |
| 忽视错题 | 反复在同一点失分 | 每次练习后整理错题日志 |
