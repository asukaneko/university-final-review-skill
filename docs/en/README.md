# University Final Review Skill Documentation

This directory contains the English documentation for the University Final Review Skill.

## Purpose

The skill helps transform university course materials into exam-ready review resources. It is especially useful when the input is a set of PPT slides, lecture notes, assignments, past papers, screenshots, or syllabus documents.

## Recommended complete request

```text
Use the university final review skill. Read the uploaded course materials and generate a complete final-exam review package, including deep chapter notes, exam point prediction, question banks, memorization outlines, worked problem-solving templates, and a 100-point mock exam.
```
