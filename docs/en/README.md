# University Final Review Skill Documentation

This directory contains the English documentation for the University Final Review Skill.

## Purpose

The skill helps transform university course materials into exam-ready review resources. It supports both technical and non-technical courses, including STEM, medicine, law, humanities, social sciences, business, education, arts, and general education.
