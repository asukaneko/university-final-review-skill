# Output Format

Use clear and exam-oriented Markdown.

## Recommended chapter format

```markdown
## Chapter N: Title

### 1. Chapter overview

### 2. Core concepts

### 3. Key mechanisms / formulas / algorithms

### 4. Exam points

### 5. Common question types

### 6. Mistake-prone points

### 7. One-page quick review

### 8. Practice questions
```

## Tables

Use tables for:

- Concept comparisons
- Exam priority ranking
- Question type mapping
- Formula summaries
- Error-prone details

## Mock exam format

A complete mock exam should include:

- Total score: 100 points
- Suggested duration
- Question sections
- Point values
- Answer key
- Scoring rubric

## Grounding labels

When needed, mark content as:

- `From uploaded material`
- `Inferred exam focus`
- `Supplementary background`
