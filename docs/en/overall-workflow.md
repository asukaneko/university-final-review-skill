# Overall Workflow

Use this workflow when the user asks for a complete university final-review package.

## Input materials

The user may provide:

- PPT slides
- Lecture notes
- Textbook excerpts
- Assignment sheets
- Past papers
- Syllabus or exam scope
- Screenshots of class materials

## Workflow

1. Identify the course name and chapters.
2. Determine the exam scope and priority topics.
3. Build a chapter map.
4. Extract core definitions, concepts, formulas, processes, algorithms, and diagrams.
5. Generate deep chapter notes.
6. Predict exam points and question types.
7. Generate practice questions.
8. Create memorization materials.
9. Add worked examples for calculation or algorithmic problems.
10. Produce a mock exam and answer key if requested.

## Default complete output

For a complete final-review package, produce:

- Course overview
- Chapter structure
- Chapter-by-chapter review notes
- Exam priority ranking
- Key definitions and concepts
- Common question types
- Mistake-prone points
- Practice question bank
- Memorization outline
- Last-minute checklist
- Mock exam

## Grounding rule

Always prioritize the user's uploaded materials. If a concept is not present in the materials but is necessary background, mark it as supplementary.
