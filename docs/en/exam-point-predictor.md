# Exam Point Prediction

This module analyzes final exam possibilities based on course materials, identifying key content and question types.

## Output per chapter

Each chapter should output:

1. Must-know points
2. High-frequency exam points
3. Low-frequency but easy-to-score points
4. Possible multiple-choice question approaches
5. Possible fill-in-the-blank question approaches
6. Possible short-answer question approaches
7. Possible essay/calculation/analysis question approaches
8. Easily confused concept comparisons
9. Review priority with 1 day left
10. Review priority with 3 hours left

## Judgment criteria

Prioritize:

- Concepts repeated across PPTs
- Content emphasized in titles, diagrams, formulas, examples
- Knowledge points appearing in assignments or experiments
- Core mechanism content for each chapter
- Content easily transformed into standard exam questions

## Priority levels

| Priority | Description | Review method |
| --- | --- | --- |
| Must-know | Guaranteed to appear, foundational for other topics | Complete mastery, can solve from memory |
| High-frequency | Appeared in multiple past papers or emphasized by instructor | Solid understanding, can explain and apply |
| Low-frequency easy | Rarely tested but easy to score if prepared | Quick review, ensure basic familiarity |
| Possible | Might appear depending on instructor's choice | Skim and note key points |

## Exam point types by question format

### Multiple-choice likely points

- Definitions and their distinguishing features
- Which of the following is correct/incorrect
- Exceptions to rules
- Specific numerical values or thresholds

### Fill-in-the-blank likely points

- Key terms and their definitions
- Formula variables and their meanings
- Steps in processes or algorithms
- Important dates, names, or numbers

### Short-answer likely points

- Compare and contrast two concepts
- Explain a mechanism or process
- List elements or conditions
- Describe an experiment or study

### Essay/calculation/analysis likely points

- Multi-step problem solving
- Case analysis requiring judgment
- Design or evaluation tasks
- Integration of multiple concepts

## Time-based priority

### 1 day before exam

Focus on:

1. Must-know points from each chapter
2. Formula/rule tables
3. Speed notes and keywords
4. Common error checklists
5. High-frequency past exam patterns

### 3 hours before exam

Focus on:

1. Speed notes keywords only
2. Formula quick reference
3. Common error patterns
4. Confidence building (review what you know well)

## Notes

Exam point prediction is not absolute guessing. Always clarify this is "exam tendency analysis based on materials."
