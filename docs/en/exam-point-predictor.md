# Exam Point Predictor

Use this module to estimate likely exam topics from course materials.

## Per-chapter output

For each chapter, produce:

1. Must-know exam points
2. High-frequency exam points
3. Low-frequency but easy-score points
4. Possible multiple-choice questions
5. Possible fill-in-the-blank questions
6. Possible short-answer questions
7. Possible long-answer, calculation, or analysis questions
8. Confusing concept pairs
9. Last-day review priority
10. Last-3-hour review priority

## Reasoning criteria

Prioritize topics that are:

- Repeated across slides
- Highlighted in titles, diagrams, formulas, or examples
- Connected to homework or lab tasks
- Central to the chapter's main mechanism
- Easy to convert into standard exam questions

## Important rule

Predictions are not guarantees. Label them as exam-oriented estimates based on the provided materials.
