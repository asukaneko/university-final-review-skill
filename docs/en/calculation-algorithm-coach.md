# Calculation / Algorithm Coach

Use this module for technical courses with calculation, derivation, scheduling, database, network, or algorithmic problems.

## Per problem type output

For each problem type, include:

1. Problem type name
2. Applicable scenario
3. Core formula, rule, or algorithm
4. Step-by-step solution method
5. Worked example
6. Common variations
7. Mistake-prone points
8. Fast exam judgment method
9. Practice questions
10. Detailed answers

## Algorithm-specific output

For algorithm topics, include:

- Core idea
- Pseudocode
- C++ implementation when useful
- Time complexity
- Space complexity
- Why the algorithm works
- Comparison with similar algorithms

## Example topics

- CPU scheduling
- Page replacement
- Memory allocation
- Master theorem
- Sorting algorithms
- Graph algorithms
- Database normalization
- Relational algebra
- TCP/IP calculations
