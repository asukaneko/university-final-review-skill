# Question Bank Generator

Use this module to create practice questions from course materials.

## Required question types

For each chapter, generate:

- Single-choice questions
- Multiple-choice questions when appropriate
- True / false questions
- Fill-in-the-blank questions
- Definition questions
- Short-answer questions
- Comprehensive, calculation, algorithm, or analysis questions

## Required metadata for each question

Each question should include:

- Correct answer
- Detailed explanation
- Related knowledge point
- Difficulty level
- Common mistake

## Difficulty levels

Use three levels:

1. Basic
2. Common exam level
3. Advanced / integrated

## Mock exam

When requested, generate a full 100-point mock exam with:

- Section names
- Point values
- Time suggestion
- Answer key
- Scoring rubric
