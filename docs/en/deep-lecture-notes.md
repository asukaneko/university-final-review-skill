# Deep Lecture Notes

Use this module to convert lecture slides or notes into detailed final-exam study notes.

## Output structure per chapter

For each chapter, include:

1. Chapter role in the course
2. Core concepts
3. Important definitions from the slides
4. Key mechanisms, processes, formulas, models, algorithms, or diagrams
5. Exam-oriented explanations
6. Common question types
7. Mistake-prone points
8. Concept comparison tables
9. One-page quick review

## Expansion rules

Do not only restate slide bullet points. For each major concept, explain:

- Why the concept exists
- What problem it solves
- How it works
- How it differs from similar concepts
- How it may appear in exams

## Style

The notes should be detailed, structured, and directly useful for university final-exam review. Prefer clear headings, compact tables, and examples over vague summaries.
