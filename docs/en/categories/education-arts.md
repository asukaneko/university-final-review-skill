# Education / Arts / Design

Use this guide for education, pedagogy, curriculum studies, art history, music, design, media production, visual communication, and creative practice courses.

## Review focus

- Educational theories, learning objectives, pedagogy, assessment, and classroom cases
- Artistic movements, works, creators, styles, media, techniques, and historical contexts
- Design principles, critique frameworks, user needs, visual language, and portfolio reasoning
- Lesson-plan analysis, work critique, reflective writing, and creative process explanation

## Recommended chapter structure

1. Key concepts, theories, works, or methods
2. Historical, educational, or design context
3. Frameworks for analysis or critique
4. Case, artwork, lesson, or project interpretation
5. Comparison between theories, styles, or methods
6. Practice prompts and model outlines
7. Rubric-based answer templates
8. Final review checklist

## Typical question types

- Concept explanation
- Theory or style comparison
- Case / lesson-plan analysis
- Artwork or design critique
- Reflective writing
- Portfolio or process explanation
- Essay questions

## Output emphasis

For education, connect theory, learner needs, teaching methods, and assessment. For arts and design, connect context, form, technique, meaning, and critique.
