# Computer Science / Engineering

Use this guide for computer science, software engineering, information systems, electronic engineering, mechanical engineering, civil engineering, and related applied technical courses.

## Review focus

- Definitions, models, architectures, and system components
- Algorithms, procedures, formulas, and engineering constraints
- Complexity, performance, correctness, reliability, and trade-offs
- Lab workflows, experiment results, and implementation details
- Typical exam calculations, coding tasks, design questions, and troubleshooting questions

## Recommended chapter structure

1. Concept map
2. Core definitions
3. Mechanism or algorithm explanation
4. Formula or derivation summary
5. Worked examples
6. Pseudocode or code when useful
7. Common design / debugging questions
8. Mistake-prone details
9. Practice problems

## Typical question types

- Multiple-choice and fill-in-the-blank definitions
- Short-answer mechanism explanations
- Calculation or derivation problems
- Algorithm tracing and complexity analysis
- Code reading or implementation
- System design or engineering trade-off analysis

## Output emphasis

For every technical topic, explain what problem it solves, how it works, when it applies, and how to solve exam problems involving it.
