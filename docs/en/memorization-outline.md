# Memorization Outline

This module is suitable for chapters or courses that require direct memorization. The goal is to convert complex content into structured materials that can be directly memorized and used in exams.

## Output content

Each chapter should include:

1. Essential keywords
2. Essential definitions
3. Standard short-answer templates
4. Essay answer frameworks
5. Directly memorizable answer paragraphs
6. Keyword chain memory techniques
7. Confusing concept comparison tables
8. Pre-exam 30-minute speed notes

## Answer style

For theory-heavy courses, answers should closely match exam paper expression:

- Begin with a definition or overall claim.
- Use numbered points for expansion.
- End with a brief summary if needed.

## Memory technique toolkit

### 1. Keyword chain method

Connect core keywords from a chapter into a story or image:

```
Keywords: process, thread, context switch, scheduling, deadlock
Chain image: A process (worker) brings threads (tools) to work in a workshop (CPU),
             the scheduler (scheduling algorithm) decides who uses equipment first,
             if two workers wait for each other's tools, deadlock occurs.
```

### 2. First-letter acronyms

Compose a meaningful word from the first letter of each key point:

```
FIFO scheduling: First In First Out → "先进先出"
STABLE sorting: Selection, Two-pointer, bubble, Insertion, linked-list, Counting → "STABLE"
```

### 3. Comparison table method

Place confusing concepts in a table for comparison:

| Dimension | Concept A | Concept B |
| --- | --- | --- |
| Definition | ... | ... |
| Features | ... | ... |
| Application scenarios | ... | ... |
| Common errors | ... | ... |

### 4. Framework fill-in method

Memorize the framework first, then fill in content:

```
Pathophysiology framework:
Risk factors → Etiology → Pathogenesis → Pathological changes → Clinical manifestations → Complications → Prognosis
```

### 5. Feynman simplification method

Explain in the simplest language to a layperson:

```
What is TCP three-way handshake?
"Making a phone call to confirm the other person is listening: Can you hear me? Yes. OK, then I'll talk."
```

### 6. Timeline method

Arrange events in chronological order, marking key nodes:

```
Software development models:
Requirements → Design → Coding → Testing → Deployment → Maintenance
```

### 7. Mnemonic/rhyme method

Turn dry content into catchy mnemonics:

```
Process states: Ready, Running, Blocked, Created, Terminated
Mnemonic: "就运阻创终" → "就云阻创终"
```

### 8. Visual association method

Convert abstract concepts into vivid images:

```
Database normal forms:
1NF (each cell has one value) → one candy per cell
2NF (non-key attributes fully depend on primary key) → all candies hang on the main rope
3NF (no transitive dependency) → candies don't pass through each other
```

## Discipline-specific memorization strategies

### Political theory / General education

**Characteristics**: Many definitions, principles, significance, and countermeasures to memorize.

**Strategy**:
- Understand the logic chain first (why → what → how).
- Organize answers in "general—specific—general" structure.
- For each point, memorize keywords first, then expand into sentences.
- Use comparison tables for similar concepts.
- Accumulate "universal phrases": opening sentences, transition sentences, concluding sentences.

**Speed note structure**:
```
I. Core definition (one sentence)
II. Main features (3-5 keywords)
III. Important significance (to whom, what significance)
IV. Practical requirements (how to do it)
```

### History

**Characteristics**: Timelines, event causality, person evaluations, significance analysis.

**Strategy**:
- Use timelines to connect events (background → process → result → impact).
- Use tables to compare similar events or people.
- Use "cause—process—result—significance" four-paragraph structure.
- Focus on memorizing "turning points" and "landmark events."

### Computer theory

**Characteristics**: Concept definitions, principle mechanisms, algorithm steps, protocol specifications.

**Strategy**:
- Use flowcharts or state diagrams to aid memory.
- Use comparison tables for similar concepts (process vs thread).
- Use "input—process—output" framework to remember algorithms.
- Use pseudocode to remember protocol steps.

### Management / Economics theory

**Characteristics**: Models, frameworks, theoretical schools, policy impacts.

**Strategy**:
- Use "assumptions—conclusions—limitations" framework to remember theories.
- Use tables to compare different theoretical schools.
- Use graphs to aid memory of supply-demand curves, SWOT matrices, etc.
- Use cases to aid memory of abstract theories.

## Pre-exam 30-minute speed checklist

In the final sprint, browse quickly in this order:

1. **Formula/rule tables** (1 minute/chapter)
2. **Common error checklists** (30 seconds/chapter)
3. **High-yield point markers** (30 seconds/chapter)
4. **Speed note keywords** (1 minute/chapter)
5. **Universal answer phrases** (2 minutes overall)
