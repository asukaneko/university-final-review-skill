# Memorization Outline

Use this module for courses or chapters that require direct memorization.

## Output sections

For each chapter, include:

1. Required keywords
2. Required definitions
3. Standard short-answer templates
4. Long-answer frameworks
5. Directly memorizable paragraphs
6. Keyword-chain memory method
7. Confusing concept comparison table
8. 30-minute pre-exam quick review

## Answer style

For theory-heavy courses, answers should use a clear exam-paper style:

- Start with a concise definition or thesis.
- Expand with numbered points.
- End with a summary sentence when appropriate.

## Best fit

This module is especially useful for:

- Political theory
- History
- General education courses
- Operating system concepts
- Software engineering theory
- Database theory
- Computer network definitions
